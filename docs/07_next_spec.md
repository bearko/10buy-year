## 1. 借金前提のイベント（A）

完済後（`s.debt <= 0`）に不自然になるセリフがある。

| イベント | 場所 | 対応 |
| --- | --- | --- |
| `month1_end` | 最初の返済日の案内 | 完済済みなら出さない（`cond: s.debt > 0`） |
| `family_call` | 「借金のことは、まだ言えなかった」 | 完済後は「借金を返し終えたことは、まだ照れくさくて言えなかった」 |
| `angry_fan` | 「僕にも返さなきゃいけない借金がある」 | 完済後は「僕にも守りたい暮らしがある」 |
| `satoshi_1` / `satoshi_2` | マイン「なんで借金してるか覚えてる？」、サトシ「借金なんて一瞬で消える」 | 完済後はマイン「借金で苦しんだこと、もう忘れたの？」、サトシ「その資金、10倍にしたくないかい？」（誘惑の方向を「借金返済」から「資産を増やす」へ） |
| `marie` | 「それで僕は借金まみれになったんだけど…」 | 完済後は「（借りるのは、もうこりごりだ…）」 |
| `ino_1` | 「借金を返さなきゃいけなくて…」 | 完済後は「もっと稼げる店を探してるんです」 |
| `ryoma_1` | 「借金を返したら、その先があるのかも」 | 完済後は「借金を返した今こそ、その先へ」 |
| `nostra_1` | オンラインサロン「予言が当たれば借金なんてすぐ返せる」 | 完済後は「老後資金2,000万円、予言で一気に…？」。勧誘文句も「借金返済」から「資産倍増」に |

- 実装：`src/data/events.js` に `const debtLine = (s, withDebt, noDebt) => (s.debt > 0 ? withDebt : noDebt)` を置き、該当セリフを差し替える。
- テスト：完済状態の state で全イベントの `play()` を実行し、出力テキストに「借金」を含むものが `debtLine` を通していることを確認する。

## 2. 「出品枠の拡張」Lv2以降でコストの予告が出ない（A・不具合）

- 原因：スキルツリー右の経験点パネル（`renderExp`）は、`!owns(s, id)` のときだけコストを「−◯」と出している。段階強化のパネルは Lv1 以上で「持っている」扱いになるため、Lv2 以降の予告が消える。
- 修正：条件を `nodeState(s, id) === 'available'`（＝まだ強化できる）に変える。詳細シートの「経験点が足りない：…」も同じ条件にそろえる。
- 同じ不具合が、今回追加した段階強化パネル16種すべてで起きる。

## 3. 仕入れ画面の「仕入れを終える」を画面下に（A）

- 一覧画面の下部に固定の「仕入れを終える」バー（高さ56px、全幅、主ボタン色）を置く。一覧の一番下にあるボタンは削除する。
- 左上の「×」は残す（閉じる操作の二重化）。商品ページでは下部は購入バーなので、左上の「‹」で一覧に戻る。
- 片手操作を想定して、在庫・出品画面の「閉じる」も同じく画面下の固定バーにそろえる。

## 4. 会話ログ（A）

- **記録**：`say` / `showInfo` / `hold`（GET!カード）/ 選択肢で選んだ答えを、`s.log` に `{ week, who, text, kind }` で追記する。最大300件（古いものから捨てる）。セーブにも保存する。
- **ボタン**：ステージ右のボタン群を「スキルツリー（全幅）／在庫・メニュー・ログ（3列）」にし、右下に「ログ」。
- **画面**：週ごとの見出し（「3年目 5月 第2週」）で区切った一覧。話し手の名前・色つき。オート中（ルーティン中）の週は見出しに「AUTO」の印。「イベントだけ」「取引だけ」の絞り込みタブ。
- オート中に選択肢が出て止まったとき、「止まるまでの◯週間のログを見る」リンクを出す。

## 5. HUD の目標欄と、目標の演出（A）

### 5.1 目標欄
- いまの「借金 ◯円」の位置を **「ステージの目標」** 欄にする。例：`Stage1 → 2：月の純利益 5万円 × 2か月（今月 3.2万円）` と進み具合のバー。
- 借金は所持金の下に小さく `借金 1,477,359円`（完済後は表示しない）。完済は目標とは別の達成として扱う。
- ステージごとの目標は `career.js` の昇格条件をそのまま文章化する（ステージ5ではエンディングまでの「最終査定の目標額」）。

### 5.2 目標が出たときの演出
- ステージが上がって新しい目標が決まったとき、全画面のポップアップを出す。
  - 大きな金額（例：**月の純利益 30万円**）、その下に条件の文章、マインちゃんのひと言、「これを目指す！」ボタン。
  - 金額は0からカウントアップして止まる（0.8秒）。効果音は `levelup`。
- ゲーム開始直後（Stage1）の目標もこの形で出す。

### 5.3 目標を達成したときの演出
- 紙吹雪：My Crypto Heroes リポジトリの `Data/Effects/GoldChest/confetti.js`（`Confetti.start(timeout, min, max)` / `stop()` / `remove()`）を `assets/vendor/confetti.js` に取り込み、`Confetti.start(2500, 120, 200)`。
- 画面中央に「達成！」の大きな帯、BGM は `win` のジングル → 昇格の演出（`stageup`）。
- 借金完済も同じ演出（紙吹雪＋`win`）。

## 6. ルーティン（B）

「同じ行動を4週」では、仕入れ→出品→売却のサイクルが自動化された実感がない。ルーティンを **サイクルのマクロ** にする。

- **ルーティン設定**（スキルツリー「ルーティン化」で解放。メニューから開く）
  - 仕入れ：行う行動（店舗せどり／電脳せどり）、買う基準（見込み利益率 ◯%以上・1回の予算上限・1商品の最大個数・偽物の手がかりが◯個以上なら避ける）
  - 出品：仕入れた物をすぐ出品するか、売り先（タブと同じ）、値付け（相場×◯）
  - 売れ残り：◯週売れなければ ◯%値下げ、◯週で即決買取
  - 実行週数（4／8／12週）
- **動き**：毎週「仕入れ（基準で自動購入）→ 出品 → 週末の売却 → 値下げ」を回す。選択肢・トラブル・イベントが出たら止まる。
- **週ごとの結果**：1行サマリー（「店舗せどり：6点仕入れ 42,300円／出品 6件／売上 3件 51,800円」）をログ（4）に残し、終わったら期間のまとめを表示。
- 外注（撮影・出品／リサーチ・仕入れ）との関係：ルーティンは自分の手で回す分（体力・時間を使う）。外注はお金を払って体力を使わない分。外注を取ると、ルーティンの対応する部分の体力消費がなくなる。

## 7. 基礎能力の効果を実感できるように（B）

いまは「パネルさえ取れば能力がFのままでもクリアできる」「鑑定士を取ると目利きが要らない」。

- **効果の見える化**：基礎能力の画面に、能力値ごとの効果を数値で出す（例：目利き 42 → 推定相場の誤差 ±18%、見られる細部 1か所／仕入れ 35 → 店舗の仕入れ候補 5件、行列の成功率 49%）。+1／+5 を押す前に「→」で変化を予告する。
- **パネルの前提に能力を使う**：主要なパネルに「目利き40以上」などの条件を足す（例：真贋の知識＝目利き30、業者オークション＝目利き50、アマクリ＝出品50、外注：撮影・出品＝出品40、問屋＝交渉60、到達点＝そのルートの能力70）。
- **鑑定士の鑑定眼を確率に**：「必ず見抜く」→「目利き×1%の確率で真贋がわかる（最大95%）」。鑑定士を取っても目利きを上げる意味が残る。
- **ランクアップの演出**：能力のランク（G〜S）が上がったとき、ステージ上にランクの文字を大きく出す。

## 8. 勉強の上位と資格（B）

問屋を解放すると「行動」「精神」の経験点が貯まりにくい。勉強の上位として **資格講座** を置く。

- 外出に「資格講座に通う」（ステージ2から、図書館で勉強の上位）。講座を選んで受講料を払い、指定の回数通うと資格が取れる。1回ごとに経験点（行動・精神が多め）。

| 講座 | 受講料 | 回数 | 取れると |
| --- | --- | --- | --- |
| 酒類販売業免許（通信販売酒類小売業免許） | 3万円 | 4回 | お酒（サケ・ネクタール）を出品できる。`noAlcohol` を解除 |
| 簿記3級 | 1万円 | 3回 | 経営画面の指標が1段増える、税額-3% |
| 古物の目利き講座（ジャンル別） | 2万円 | 3回 | そのジャンル（時計・ジュエリー・楽器…）の推定誤差-20%、細部チェック+1 |
| 輸出入の基礎（ステージ3〜） | 5万円 | 4回 | 海外の販路「海外EC」（下の9.1）を解放 |
| 店舗経営講座（ステージ4〜） | 10万円 | 5回 | 自分の店（下の9.2）を開ける |

- 酒類は現状「出品できない」だけで解除方法がないので、この免許で「売る方法」を用意する（免許なしで出品すると規約違反＋TOKU減）。

## 9. 商品ジャンルの拡張と自分の店（C）

### 9.1 ジャンルの拡張
- ステージ3・4で、エクステンションの商品を増やす（MCH のエクステンション画像を追加で取り込む）。候補：カメラ・レンズ、ゲーム機・ソフト、ブランドバッグ、アート・版画、スニーカーのコラボ新作、アンティーク家具（大型・置き場を圧迫）。
- ジャンルごとに「知らないと仕入れられない」。資格・講座（8）やスキルツリーで **ジャンル知識** を得ると、そのジャンルの仕入れ候補が出るようになる。仕入れ画面に「未知のジャンル：？？？」として並べ、何かがあることだけ見せる。
- 海外の販路（輸出）：円安の週は売値が上がる、関税と送料。

### 9.2 ステージ4：自分の店
- 「店を持つ」を選ぶと、立地と客層を選ぶ。

| 立地 | 家賃／月 | 客足 | 得意な客層 |
| --- | --- | --- | --- |
| 駅前 | 高 | 多 | 通勤客・観光客 |
| 商店街 | 中 | 中 | 地元のコレクター |
| 郊外ロードサイド | 低 | 少（車） | ファミリー |
| 観光地 | 高 | 季節で波 | インバウンド |

- 客層ごとに売れるジャンルと値付けの許容が違う。店の在庫（陳列）を選び、毎週の客足×購買率で売れる。改装（内装・看板・EC併設）、スタッフ雇用、買取カウンター（仕入れ候補が店に来る）でやり込み。
- 店のKPI：客単価・坪効率・在庫回転。経営画面に店のタブ。

### 9.3 実装メモ
- **新ジャンル**：アート・美術品（版画）、レトロゲーム・PC、アンティーク（ロッキングチェア＝大型、オルゴール、漆器）、ブランド小物（スカーフ）、ステージ4の高額品（モアイ）。商品データに `know`（ジャンル）と `stage`。
- **ジャンル知識**：資格講座「◯◯の基礎講座」（4万円・3回・ステージ3〜）で `know_<ジャンル>` の資格。知らないジャンルは相場画面にも出ず、仕入れ画面に「未知のジャンル ？」のカードが混ざる（タップで、どの講座で学べるかを案内）。
- **海外EC**：資格「輸出入の基礎」で解放。手数料13%、送料3倍、売値×為替（`s.fx` 0.9〜1.35 を毎週ゆらす）。
- **自分の店**：資格「店舗経営講座」のあと、外出「店を開く」で立地を選ぶ（保証金＝家賃3か月）。出品していない在庫が店頭に並び、毎週「客足×購買率」で売れる（手数料・送料なし、値段は相場×立地の許容）。月末に家賃（スタッフを雇えば給料も）。メニュー「自分の店」で先週の来客・売れた数・客単価を見て、改装（客足+30%・3段階）、スタッフ（購買率アップ）、買取カウンター（近所の持ち込みを相場の4割で買い取る）。

### 9.4 調整（自動プレイ）
- 表の方針の bot（講座で輸出・2ジャンル・店舗経営を取り、商店街に出店）：10/10がステージ5、平均資産 約7,900万円、破産0。店の売上は開店から4年で 7,000万〜1.2億円。

## 10. TOKU（徳）と、表のルート／魔道のルート（C）

### 10.1 TOKU
- 「炎上度」を **TOKU** に置き換える。基準100、0〜200。日々の活動への影響は小さく、キャリアの分かれ道になる数値。
- 下がる行動：品薄品の買い占め、捨てアカ・名義借りの抽選、規約違反の出品、偽物・盗品の販売、クレームの放置、行列の割り込み。
- 上がる行動：公式リセールでの定価譲渡、困っている人への定価販売、丁寧な取引（評価）、寄付・地域のイベント、違法な誘いを断る。
- HUD の「炎上」欄は「TOKU」に。今の炎上度からの移行は `TOKU = 100 − 炎上度`。

### 10.2 表のルート（TOKU ◯以上で取れるパネル）
- スキルツリーに「TOKU 120以上」「140以上」「170以上」の条件つきパネル群。健全な事業としての物販：正規代理店契約、メーカー直取引の拡大、法人の信用（融資枠）、従業員の育成、専門商社→総合商社。
- 究極形は到達点「**総合商社**」（または「専門商社」）。エンディングも対応させる。
- 取得に時間とお金はかかるが、失うものはない。

### 10.3 魔道のルート（TOKU ◯未満で取れるパネル）
- 「TOKU 80未満」から開く裏のパネル群。コストは安く、すぐ強い（転売ボットの購入、並び屋の手配、名義の大量取得、偽物の卸、盗品の買い取り…）。
- 1枚取るごとに TOKU が下がる（引き返しにくくなる）。**TOKU が0になると「裏の人間」** に。TOKU のゲージ自体が消え、元には戻らない。

### 10.4 裏の人間
- プンシー・ミィーム・アマクリはアカウント凍結。売買は「裏のサービス」（闇市・裏オークション・ブローカー）だけ。
- 金額の規模は表の数倍〜10倍。生活水準が上がり、毎月の生活費も大きく上がる（金銭感覚の麻痺）。
- 商売敵や恨みを買った相手からの報復イベント（袋叩きで体調不良・在庫の強奪）。低確率で襲撃されてゲームオーバー（エンディング「闇に消えるEND」）。
- ハイリスク・ハイリターンのまま10年を走り切ることもできる（エンディング「裏社会の帝王END」）。

### 10.5 蜘蛛の糸（足を洗う救済）
- 裏の人間になったあと、条件（例：ある偉人との縁、一定期間の我慢）で「足を洗う」イベントが出る。
- 選ぶと、所持金・在庫・事業・スキルツリーのパネルは **すべて失う**。残るのは基礎能力だけ。TOKU は50から再スタート、表のサービスは「保護観察」（手数料が高い）から。
- 生活水準を落とす恐怖を演出（「この暮らしを捨てるのか？」の確認を2回）。選べた人だけが表に戻れる。エンディングにも反映（「蜘蛛の糸END」）。

### 10.6 実装メモ
- **TOKU が動くもの**：下がる＝規約違反（捨てアカ -4、名義借り）、偽物を知らずに売る -3、クレームの無視、炎上イベント、魔道のパネル（1枚 -15、裏社会の帝王 -100）。上がる＝公式リセールでの定価譲渡 +10、違法な誘いを断る +3〜8、謝罪・炎上の鎮火、評価95以上を保つ（毎月 +1）、外出「寄付・地域の手伝い」（無料 +2／10万円 +3／100万円 +15）。
- ふだんの商売の炎上（高値の転売・行列・自然に冷める分）は TOKU には響かない（`addHate(s, n, false)`）。炎上度は内部の値として残し、HUD では「炎上中」の警告だけ出す。
- **表のルート「正道・商社」**（7枚）：公正な取引（TOKU110〜）→ 正規代理店契約・事業の信用（120〜）→ 従業員の育成・メーカー直取引の拡大（140〜）→ 業界の信頼（150〜、月+50万円）→ 総合商社（170〜、月+150万円・買い手+20%）。
- **魔道のルート**（6枚、TOKU80未満）：転売ボット → 並び屋の手配・名義の大量取得 → 偽物の卸（月+30万円）・盗品の買い取り → 裏社会の帝王（裏の人間になる）。
- **裏の人間**：表の販路（プンシー・ミィーム・アマクリ・海外EC）は凍結、出品は取り下げ。売り先は「裏市場」（仲介料20%、売値×2.5、帝王なら×3）。生活費 月35万円。報復（体調不良・在庫の強奪）、まれに襲撃で「闇に消えるEND」。確定申告はしない。

- **エンディング**：闇に消えるEND（襲撃）、裏社会の帝王END（裏の人間のまま10年）、蜘蛛の糸END（足を洗って10年）。
