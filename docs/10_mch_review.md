# MCH運営への事前確認資料

一般公開の前に、My Crypto Heroes（MCH Co., Ltd.）の運営に内容を確認してもらうための資料。
[MCH デザインガイドライン](https://medium.com/mycryptoheroes/mch-design-guideline-ja-99ff0970ccdc)の禁止事項「ゲームイメージを損なう内容」「公序良俗に反する内容」に、転売という題材が当たらないかを見てもらうのが目的。

> 運営への連絡そのものは人の作業。この資料は、送る文面のたたき台と、見てもらうポイントの一覧。

---

## 1. 作品の概要

| 項目 | 内容 |
| --- | --- |
| タイトル | 10 buy year!（テンバイヤー） |
| ジャンル | 転売（物販）の経営シミュレーション。1週ずつ進めて10年で借金を返す |
| 形態 | ブラウザゲーム。ビルドなしの静的サイト。ログイン・課金・広告なし（コードにも仕組みがない） |
| 公開先 | Vercel（現在の確認用URL：https://10buy-year.vercel.app/） |
| 遊ぶ時間 | 1周 2〜4時間ほど。セーブはブラウザ内（localStorage）だけ |
| ねらい | 転売を「良い・悪い」で裁くのではなく、相場・手数料・在庫・税金・法律を体験して知ってもらう。違法な転売はゲーム上も大きな罰がある |

クリス・マイン・マイクリくんはリポジトリオーナーが権利を持つオリジナルキャラクター（ドット絵：こじもこ）。

### ヒーローの役どころ

ヒーローは「転売ヤーそのもの」にはせず、自分の逸話で語る師匠・客・誘惑役にしている（`docs/02_game_design.md` 11章）。

| ヒーロー | 役どころ | 確認してほしい点 |
| --- | --- | --- |
| 一休・徳川家康・伊能忠敬・ニュートンほか（師匠役） | 知恵・我慢・測量（相場の記録）を教える | なし |
| 平賀源内 | 「土用の丑の日」の販促アイデア | なし |
| マルクス | 「G–W–G′（お金→商品→増えたお金）」で転売の仕組みを風刺 | 風刺の表現 |
| マリー・アントワネット | 高く買ってくれる客。「お金がないなら、借りればいいじゃない」 | 借金を勧める台詞（風刺として） |
| 楊貴妃 | 美容系インフルエンサー。ステマ（PR表記なし）の誘い | ステマを断れる選択として出している |
| サトシ・ナカモト | 仮想通貨の誘い。作中の架空コイン「$SAOコイン」 | **ブロックチェーンゲームの運営として、仮想通貨をギャンブル的に描く点** |
| 石川五右衛門 | 裏ルート（盗品・偽物の卸）への誘い役 | **偉人を犯罪の誘い役にしている点** |
| 織田信長 | 「楽市楽座」で既得権を壊す人として、大きな商いを勧める | なし |
| サンタクロース・ナイチンゲールほか | 季節の客・体調の助言など | なし |

## 3. 題材の扱い方（トーンの方針）

1. **真剣に**：手順・数字・制度はなるべく正確に。法律の説明は `docs/12_law_review.md` で年1回見直す
2. **貶めない**：プレイヤーを悪者扱いしない。批判の声はSNSの一投稿として、感謝の声と並べて出す
3. **違法は違法**：チケットの高額転売・盗品・偽物・無申告は明確にNG。ゲーム上も逮捕・追徴課税・アカウント停止などの大きな罰がある
4. **偉人は偉人として**：転売ヤーそのものにはしない
5. **実名を出さない**：実在のゲームタイトル名はゲーム内に出さない（テストで自動チェック）。販売サービスはパロディ名

## 4. 特に見てほしい場面

ガイドラインに照らして判断が分かれそうなもの。指摘があれば、データの書き換えだけで差し替えや削除ができる。

| # | 場面 | どこにあるか | 指摘があったときの対応案 |
| --- | --- | --- | --- |
| 1 | **裏ルート（魔道）**：盗品・偽物の卸で稼ぐスキルツリーの枝と「裏社会の帝王END」「闇に消えるEND」 | `src/data/skills.js`（route: dark）、`src/engine/ending.js` | 枝ごと削除し、裏市場は「誘われて断る」イベントだけにする |
| 2 | 石川五右衛門が盗品・偽物の誘い役 | `src/data/events.js` | 役をオリジナルのモブ（怪しい業者＝エネミー410）に替える |
| 3 | 仮想通貨の誘い（サトシ・ナカモト、$SAOコイン）と「結局クリプトEND」 | `src/data/events.js`、`src/engine/crypto.js` | イベントを外すか、MCHと無関係な架空の投資話に替える |
| 4 | 販売サービスのパロディ名「プンシー（OpenSea）」「ミィーム（miime）」 | `src/engine/inventory.js` の PLATFORMS | MCHと縁のあるサービスのパロディが不適切なら、無関係な名前に替える |
| 5 | エネミーを「クレーマー」「詐欺師」など人として描く | `src/data/cast.js`、`src/data/troubles.js` | 問題ないかの確認だけ |
| 6 | 借金・債務整理・逮捕のEND | `src/engine/ending.js` | 問題ないかの確認だけ（説教ではなく結末として出す） |
| 7 | 商品（エクステンション）の名前をゲーム用に付け替えている | `src/data/products.js` | 元の名前に戻す／英語名を使う、など指定に合わせる |

## 5. 見てもらう方法

- URL を開き「はじめから」。チュートリアル（最初の1〜2か月）で、題材の扱い方の雰囲気はわかる
- 裏ルート・仮想通貨・ENDの一覧は、リポジトリの該当ファイルか、この資料の表で確認してもらう
- 画面の全体像は README のスクリーンショット、または確認用URLで
