# 09 仕入れの現場（店舗巡り・夜のスマホ・メール）設計と実装メモ

「買って売る」の繰り返しに、**実際に仕入れている手ざわり**を足すための設計。
店舗せどりは「回った店の、その棚の前で買うかを決める」、電脳せどりは「夜のスマホでアプリを渡り歩く」体験にした。
売れた知らせや抽選結果はメールで届く。行列は整理券から販売までを見せる。

## 1. リサーチ（実際のせどりでやっていること）

| 場面 | 実際の動き | ゲームへの落とし込み |
|---|---|---|
| 店舗せどりのルート | 地図アプリで回る店と順番を決め、1日に数店〜10店ほど回る。遠征では地図で店を探す | 閉店までの時間で回る。次の店を2択で選ぶ。地図スキル・車で移動が短くなる |
| 店内で見る場所 | 入口の処分ワゴン、値札・POP（廃番・展示品）、ショーケース、棚の上下やエンド棚、旧パッケージ | 店ごとに「売り場（棚）」があり、品定めに時間を使う。何もない棚もある |
| 店での判断 | その場で検索アプリやビーム（バーコード読み取り）で相場を調べて、買うか決める | 商品ページで「スマホで相場を調べる」（数分かかる）→ カゴ → レジ |
| フリマでの仕入れ | 保存した検索条件の新着通知、販売中・売り切れの絞り込みと新しい順、いいね数、コメントでの値下げ交渉。安い出品はすぐ売れる | 通知から商品へ飛ぶ。売り切れ検索で相場を確かめる。コメントで値下げ交渉。時間がたつと他の人に買われる |
| ネットオークション | 上限額を決めて自動入札。自動延長のない出品は終了間際に入札。タイトルミス・カテゴリ違いを狙う | 上限額で入札、すぐに高値更新されることもある。自動延長なしなら終了間際の入札でライバルが上げ直せない |
| 売れた知らせ | 「商品が購入されました。発送をお願いします」のメールが届き、梱包・発送・発送通知 | 週のはじめにメールボックスを開き、購入通知・落札通知・流札を読む |
| 抽選・行列 | 結果はメール（深夜に届くことも）。行列は整理券、入荷数と自分の番号の勝負 | 抽選結果はメール。行列は 始発 → 整理券 → 開店 → 販売 の演出 |

## 2. 実装したもの

### 2.1 店舗巡り（店舗せどり）— `engine/sourcing.js`・`ui/storerun.js`

- 12:00に出発、20:00閉店（夜の店舗せどりは18:30〜22:00）。
- **移動**：店ごとに距離が違う（基本50分×0.6〜1.5）。地図スキル（大日本沿海輿地全図）-30%、車 -40%。
- **品定め**：売り場1か所につき基本35分。仕入れの能力で最大-40%、AIリサーチツールで-40%。
- **流れ**：次の店を2択で選ぶ → 移動の演出 → 店の看板と入店のひとこと → 売り場を選んで品定め（ガサゴソの演出）→ 目に留まった品 → 商品ページ（スマホで相場を調べる：3分）→ カゴ → レジ（5分、レシート）→ 次の店へ／帰る。
- **店の種類（店名はすべて架空）**：家電量販店・ドラッグストア・雑貨屋・ホビーショップ・リサイクルショップ・古本屋・ブランド正規店、それに開拓した仕入れ先。品の種類ごとに置かれる店が決まっている（中古はリサイクルショップ、限定品はホビーショップなど）。
- **回れる店の数**：最初は2〜3店舗。地図・AI・仕入れの能力・車がそろうと6〜8店舗。
- **見つかる品の数**：ふつうに回ったとき（ルート順に全部の棚を見る）に、これまでの仕入れ候補の数（`storeOfferCount`）になるよう、ルート全体に品を散らす。届かない店の品は、届く店のうち種類の合う店へ移す（開拓先・品薄品を優先）。開拓した仕入れ先はルートの前のほうに入る。

### 2.2 夜のスマホ（電脳せどり）— `ui/phone.js`

- 21:00〜深夜1:00。行動ごとに時計が進む（商品を開く2分・売り切れ検索5分・質問15分・値下げ交渉20分・購入2分・広告を誤タップ5分）。
- **ロック画面の通知**：保存した検索の新着・在庫復活・予約開始・ウォッチ中のオークション終了間際。タップで商品へ直行。
- **アプリ**：プンシー（フリマ）、ミィーム（オークション）、マイクリ市場（通販モール）、GLOBAL☆DEAL（海外通販）。並べ替え（新しい順・安い順・終了が近い順・ポイント還元順）。
- **相場どおりの出品**：フリマとモールに、相場前後の値段のふつうの出品を混ぜる（買えるが利益はほぼ出ない）。この中から安い出品を探す。
- **売れてしまう**：フリマの安い出品・在庫復活・予約には「売れるまでの時間」があり、相場より安いほど早く消える。値下げ交渉の返事を待つ間に売れることもある。
- **値下げ交渉**：-5%／-10%／-20%。業者っぽい出品者は渋い。大きく値切るとブロックされることも。
- **オークション**：フリマ出品の一部はオークション形式。上限額で入札すると、ライバルの上限を超えていなければすぐ高値更新される。自動延長なしの出品は「終了間際に入札」でライバルの上限が1割下がる（その時刻まで起きている必要がある）。寝た後に終わるオークションは、ふつうの入札だけが上限額のまま競る。
- **深夜1時**：「寝る」か「夜更かし（+60分・体力-8）」を選ぶ。
- **広告**：一覧の間に、世界観の広告（相場大予言サロン、五右衛門卸、サトシの投資塾、楽市楽座 倉庫レンタル、マイクリ英雄ガチャ など）。

### 2.3 メールボックス — `ui/mail.js`

- 週の取引結果の前に、メールアプリが開いて新着が1通ずつ落ちてくる。購入通知・落札通知・流札、ときどき迷惑メール（GUM凍結の詐欺メールなど）。
- 抽選の結果（当選・落選）もメールで届く（`turn.js` の `mail` ステップ）。

### 2.4 行列 — `ui/queue.js`

- 始発5:12 → 6:30 整理券（番号と入荷数）→ 10:00 開店 → 前から順に売れていき、自分の番号まで在庫がもつか。

### 2.5 オート・バランス

- ルーティン・外注・テストのボットは `autoVisible` で「ルート順に棚を全部見て、これまでの数まで」だけを見る。相場どおりの出品は見ない。
- 自動プレイ40回×3通りのシードで、変更前と同じくらいの到達ステージ・資産になることを確かめた（変更前も、シードによって40回中3〜5回は破産する）。

### 2.6 店内の見取り図と、店にいる人たち — `ui/storerun.js`・`engine/storefolk.js`

- 店に入ると店内の見取り図が出る。売り場（棚・ワゴン・ショーケース・コーナー）をタップすると、クリスがそこへ行って品定めする。セール品のワゴンは入口の近く。棚には商品が並んでいる。
- 店員（ヒーロー）・買い物客（ヒーロー）・同業者（エネミー）が店にいる。話しかけられないが、吹き出しで独り言（10文字以内）が見える。
- ときどき頭の上にオレンジの「！」。タップすると出会いのイベント：
  - ヒーロー：ひとこと助言と経験点（その人にちなんだ種類）、またはミッションの依頼
  - 店員：バックヤードの在庫を出してくれる（売り場に「店員さんのおすすめ」が増える）
  - 同業者：仕入れ先のうわさ（開拓が3回分進む）と情報の経験点
- カゴに入れた後も、商品ページの下のバーかカゴの中身で個数を変えられる。
- 商品ページは、写真と値段を上に小さくまとめ、「商品の情報／相場（スマホで相場・交渉・オークション）／自分のメモ」をタブで切りかえる。スクロールしなくても見られる。

### 2.7 ミッション — `engine/quests.js`・`ui/quests.js`

- お金の目標とは別の小さな目標。マインが週のはじめに告げるもの（ステージに合わせて1つずつ）と、店で出会ったヒーローから頼まれるものがある。同時に3つまで、24週で期限切れ、あきらめることもできる。
- 使ったことのない機能へのきっかけにする。例：「借金を10万円、繰上げ返済する」→ ミッション画面の「やってみる」でメニューの「経営」が開く。ほかに、独占契約（業界の動き）、取引方針、出資、コレクションなど。
- 報酬はお金ではなく、まとまった経験点か新しい仕入れ先（回数を待たずに開拓）。
- 右の「スキルツリー」ボタンの上に、同じ大きさの「ミッション」ボタン（青緑）。新しいミッションがあると「！」。
- ヘッダーを詰めた分、中央のステージを34px高くした。縦が短い画面では、右の欄のボタンを詰めて収める。

## 3. 提案（まだ実装していない演出）

優先度：◎すぐ効く ○中くらい △大きめ

### 3.1 ほかの行動

| 行動 | 演出の案 | 優先 |
|---|---|---|
| 撮影・出品作業 | 撮影ミニ演出：背景（白布・木目）・光（窓際・リングライト）・枚数を選ぶと、写真の質が上がり売れやすくなる。採寸・説明文テンプレ（源内のコピー講座） | ◎ |
| 発送 | 朝の梱包ラッシュ：売れた品ごとに箱のサイズを選ぶ（大きすぎると送料が上がる、小さすぎると入らない）→ コンビニ持ち込み。発送通知メールを送る | ◎ |
| 業者オークション | 会場の競り：ロットが順番に流れ、数秒の間に「手を挙げる／下ろす」。プロの目利き（ゴースト・ゴッホ）と競る | ○ |
| 問屋と商談 | 見積書の画面：掛け率と最低ロットを対人の経験点で交渉。支払いサイト（翌月末払い）で資金繰りが変わる | ○ |
| 抽選に応募 | 応募フォーム（名前・住所・会員番号の入力演出）。家族名義・複数アカウントの誘惑がフォームの横に出る | ○ |
| 物販交流会 | 名刺交換の演出。名刺が「人脈」のコレクションになり、のちの仕入れ先の紹介につながる | △ |

### 3.2 転売で生活する人の暮らしの疑似体験

| 案 | 中身 | 優先 |
|---|---|---|
| 部屋が段ボールで埋まる | 在庫量に応じて、家の背景に段ボールが積み上がる。置き場を超えると寝る場所がなくなる演出 | ◎ |
| クレカ請求・引き落としメール | 月末に「ご利用代金確定のお知らせ」。残高不足ならリボの案内が届く | ◎ |
| 月曜の朝のチラシ | 週のはじめに、セールのチラシ・アプリのクーポン通知。店舗巡りのルートを考える材料になる | ○ |
| 天気 | 雨の日は店がすいていてワゴンが残る、行列が短い。台風の週は配送が遅れる | ○ |
| SNSのタイムライン | せどり仲間・ライバルの投稿（「○○が売れてる」「この店は荒れた」）。うわさは当たったり外れたりする | ○ |
| 確定申告 | 2〜3月にレシートと帳簿の山。三成（帳簿の鬼）に手伝ってもらうと楽 | △ |
| 寝不足 | 夜のスマホで夜更かしを続けると、翌週の判断ミス（偽物を見落としやすい）が増える | △ |
