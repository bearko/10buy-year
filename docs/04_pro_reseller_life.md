# 追加調査：専業転売屋の生活と商材別の実態

「転売屋の解像度を上げる」ための追加の参考資料。
店舗せどり寄り＋一部電脳・外注活用の専業層をベースにした**合成像**で、2025〜2026年頃の傾向を中心にしている。

> 出典：プロジェクトオーナーから提供された追加調査（2026年9月）。個々の数字（走行距離、月利など）はよくある例として扱い、ゲームに使うときは誇張・簡略化してよい。
> ゲームへの反映案は末尾の「[ゲームへの落とし込み](#ゲームへの落とし込み)」にまとめた。

## 1. 一日のスケジュール

専業の多くは **「朝は事務・発送、日中は仕入れ、夜は出品・リサーチ」**。睡眠を削る人も少なくない。
典型例：店舗メインの専業、月利数十万〜100万円超クラス。

| 時間帯 | やること |
| --- | --- |
| 5:30〜7:00 | 起床。スマホで売上通知・取引メッセージを確認（大手EC、フリマ、オークション）。価格改定ツールを回す。家族がいれば朝食や会話 |
| 7:00〜8:00 | 前日・当日の注文分を梱包し、ラベルを印刷。運送会社の営業所や郵便局へ。**朝イチで出すのが鉄則**（遅れると評価ダウン） |
| 8:00〜12:00 | 仕入れに出発。家電量販店・ディスカウントストア・ホームセンター・リサイクルショップを2〜5店舗。開店直後を狙う人が多く、車で県をまたぐ人も（1日500〜600km走る例も）。移動中は音声で情報収集や勉強 |
| 12:00〜13:00 | 昼食。コンビニかチェーン店で効率重視（「美味い店探し」が唯一の趣味という人も） |
| 13:00〜18:00/19:00 | 午後の仕入れ。閉店時間を意識してルートを組む。**疲れてくる時間帯で判断ミスが増えやすい** |
| 19:00〜21:00 | 帰宅して検品・撮影・出品登録。パソコン2〜3台を並べて作業する人も |
| 21:00〜24:00/1:00 | 夜の電脳リサーチ（通販サイトとフリマの相場チェック）、価格改定、メッセージ対応、外注への指示。翌日の仕入れリストを作る |
| 深夜〜早朝 | 睡眠4〜6時間。朝方まで作業して昼に寝る人も |

**生々しいポイント**
- ガソリン代・高速代がかさむ。腰や足が痛くなる。
- 在庫が部屋や倉庫を占領し、生活空間が圧迫される。
- 売上通知が鳴るたびにテンションが上がり、売れ残り在庫を見ると落ち込む。
- 外注を使うと「外注先への指示・検品」でさらに時間が取られる。
- 電脳中心の人は外出が減り、在宅でのリサーチ・出品が中心。アパレル・ブランド系は撮影と採寸に時間がかかる。

## 2. 週のリズム

| 曜日 | 特徴 |
| --- | --- |
| 月 | **発送が特に忙しい**（週末の注文の山）。倉庫への納品や大口発送。週初めの価格改定・在庫確認 |
| 火〜木 | 通常仕入れのメイン。平日は店舗が空いていて狙いやすい。ポイント還元日を狙った電脳仕入れ。リサーチを深める |
| 金 | 週末に向けた仕入れ強化。閉店セール情報の最終確認。週末用の在庫を多めに確保 |
| 土 | 店は混むが、チラシセールや週末限定が狙い目。午前は家族、午後から仕入れという人も |
| 日 | 仕入れを続けるか完全休養かに分かれる。通販のポイントイベントを狙う電脳勢が多い。週末の注文の発送準備 |

**生々しいポイント**
- 「週末は家族と過ごしたいが、売れ筋を逃したくない」という葛藤。
- 外注が休みの日は自分で全部やる羽目になる。
- 月曜の発送地獄で疲れがピークになる。

## 3. 月ごとのイベント（シーズン）

季節とセールが仕入れ・販売のピークを作る。外すと利益が大きく落ちる。

| 月 | 主なイベント・動く商材 |
| --- | --- |
| 1月 | 初売り・福袋・年末年始のクリアランス。おもちゃ量販店の決算セール。赤本など受験関連 |
| 2〜3月 | バレンタイン・ホワイトデー・ひな祭り。花粉対策グッズ。新生活（入学・就職）で家電・収納の需要増。リサイクルショップに不用品が集まる。確定申告で事務作業が増える |
| 4〜5月 | 新生活・ゴールデンウィーク。母の日。アウトドア・キャンプ用品が動き始める |
| 6〜7月 | 父の日・お中元。梅雨・夏物（扇風機など）の仕入れ強化。ボーナス期でポイント還元が熱い |
| 8月 | 夏休み・お盆。夏祭り関連、冷感グッズ。在庫処分を意識 |
| 9〜10月 | 秋物・行楽。ハロウィン。ゲーム新作や限定品が動きやすい |
| 11月 | ブラックフライデー・年末商戦の準備。クリスマスのおもちゃ仕入れが本格化。決済サービスの大型ポイント祭 |
| 12月 | クリスマス・年末。おもちゃ・家電が爆発的に動く。**発送がパンクしやすく、クレームも増える**。在庫を売り切る勝負の月 |

**毎月の定番**
- 毎月5・15・25日などのポイントアップ日。
- 月末の在庫確認と損切り判断。

**生々しいポイント**
- クリスマス前は「親心を狙って高値で売る」意識が強くなる人も。
- シーズンを外した在庫は倉庫に積み上がり、資金が寝て精神的にきつい。
- 大型セールの日は夜中までリサーチして寝不足になる。

## 4. 専業の「全体的なリアル」

- **自由だが不自由**：時間は自分で決められるが、売上が落ちるとすぐに焦る。毎日「今日いくら仕入れたか」「いくら売れたか」を頭で計算している。
- **体への負担**：車移動で腰痛・肩こり、梱包で指が痛む。睡眠不足が慢性化しやすい。
- **人間関係**：家族からは「いつまでやるの？」。外注や仕入れ先との連絡でストレス。
- **精神面**：当たりの日はハイ、外れの日は落ち込む。在庫を抱えた夜に「損切りすべきか」と悩む。
- **お金の流れ**：現金仕入れが多く、手元資金の管理がシビア。税金・古物商の手続きも必須。
- **スタイルの違い**：月利100万円超で外注をフル活用している人は事務・指示が中心。並び屋から上がってきた人は不規則で夜間の活動が多い。
- **共通する声**：「自分のスタイルを確立するまでが地獄」。

## 5. 商材別の苦労と戦略

### 5.1 チケット（コンサート・スポーツ・イベント）
| 観点 | 内容 |
| --- | --- |
| 仕入れの苦労 | 抽選倍率が非常に高い。複数アカウント・代理購入は規約違反や法的リスク（チケット不正転売禁止法）。並び屋や組織的な買い占めとの競争 |
| 販売の苦労 | 定価超えの販売は違法になりやすい。プラットフォームの出品制限・削除が強化。クレームや通報が多く、アカウントBANのリスクが高い |
| 戦略・トレンド | 公式抽選や会員優先が主流。興行側のシリアル管理・購入履歴フィルターが強化され、大量購入は困難に。越境転売も一部あるがリスク大 |

### 5.2 限定スニーカー・ストリートウェア
| 観点 | 内容 |
| --- | --- |
| 仕入れの苦労 | ほぼ抽選販売で当選率が極端に低い。メーカーアプリの転売対策が厳しく、複数端末や住所分散に走りがち。偽物が非常に多い（特に中古・フリマ仕入れ）。**サイズごとの需要差が激しい** |
| 販売の苦労 | 再販やブーム終了で相場が急落し赤字に。**サイズ違いによる返品・クレーム**。真贋鑑定を求めるプラットフォームが増え、偽物を売るとアカウント停止や訴訟リスク |
| 戦略・トレンド | 抽選当選＋デッドストック（未使用）重視。中古は人気サイズ・良状態を知識で狙う。2026年時点でメーカーの転売排除が強まり、安定仕入れが難しい。海外需要を意識した戦略も一部で続く |

### 5.3 ゲーム機・ソフト・トレカ・フィギュア・プラモデル
| 観点 | 内容 |
| --- | --- |
| 仕入れの苦労 | 新機種の発売時は品薄・抽選・個数制限が激しい。並びや複数人での買い占めが常態化。トレカは未開封BOXの大量仕入れやレア判別（**金属探知機を使うケースも**）で資金と手間がかかる。偽物・コピー品が多い |
| 販売の苦労 | ブーム終了や再販で急落。在庫で資金が固定される。トレカは状態管理が厳しく開封後のクレームが多い。人気ゲーム機関連などでフリマ側の出品制限が増えている |
| 戦略・トレンド | 発売直後のプレミア狙いから、**レトロ・廃盤品の中古仕入れへのシフト**。閉店セールやリサイクルショップの掘り出し。シリアル管理・プレイ実績フィルターで新品転売は難化。トレカは卸・専門店ルートや海外需要 |

### 5.4 家電・スマホ・ガジェット・カメラ
| 観点 | 内容 |
| --- | --- |
| 仕入れの苦労 | 型落ちやワゴン品の目利きが必要。人気機種は個数制限・抽選化。**ジャンク品は動作確認の手間**が大きい。中国輸入は為替・検品・関税・薬機法などのトラブルが増加 |
| 販売の苦労 | **新モデル発表で旧型が急落**。返品率が高め、状態説明のミスがクレームに。高額品は送料・梱包コストがかさむ |
| 戦略・トレンド | 2025〜2026年は「店舗仕入れの復権」。閉店セール・量販店の在庫処分を狙い、通販のポイント還元と併用するのが主流。**AIツールで「大手ECで在庫切れの商品」を逆引きして店舗へ行く**手法が広がっている。中古スマホは安定需要 |

### 5.5 ブランド品（バッグ・時計など）・古着
| 観点 | 内容 |
| --- | --- |
| 仕入れの苦労 | 真贋判定の知識が必須で偽物リスクが高い。古着は流行の移り変わりが早い。**業者オークションや質屋ルートは資金と会員資格が必要** |
| 販売の苦労 | 鑑定・認証の手間とコスト。季節・トレンドで動きが鈍い。高額品は購入者が慎重でキャンセル・クレームが出やすい |
| 戦略・トレンド | 過去の落札価格データを使った仕入れが主流。ヴィンテージ・ワークウェアは海外需要が強い。偽物対策で信頼できるルート（業者オークション等）へシフト |

### 5.6 本・コスメ・日用品
| 観点 | 内容 |
| --- | --- |
| 仕入れの苦労 | 赤本・専門書はシーズン性が強く、時期を逃すと在庫化。コスメは使用期限や並行輸入の規制に注意。大量仕入れで過剰在庫になりやすい |
| 販売の苦労 | 回転が遅いと資金が寝る。コスメは薬機法関連で出品削除されることがある |
| 戦略・トレンド | 本は古本チェーンの店舗仕入れ＋電脳が定番。コスメは限定品を少量から。流行り物より定番・型落ちの「安定回転重視」が強まっている |

### 5.7 全体のトレンド（2025〜2026年）
- **メーカー・プラットフォームの転売対策強化**：抽選化、購入履歴フィルター、シリアル管理、フリマ側の出品制限。単純な新品の大量仕入れは難しくなっている。
- **店舗仕入れ＋電脳せどりのハイブリッド**：閉店セール・ワゴン品に、通販のポイント還元で利益を上乗せ。
- **AI活用**：相場・需要予測・在庫切れ商品のリサーチにAIを使う人が増加。
- **在庫リスクの低減**：大量仕入れより少量・高回転。損切りの判断を早くする。
- **古物商許可はほぼ必須**（中古を扱う場合）。フリマ大手は、事業者に事業者向けショップ機能への移行を求める動きがある。
- **中国輸入の難化**：円安・検品トラブル・規制強化。

## 6. 転売あるある

- 売れ筋を見つけて大量仕入れしたら、翌日にはライバルが殺到して相場が崩れた。
- 抽選に応募しまくったのに全部外れ。並び屋に日当を払ってやっと仕入れた。
- フリマで「転売ヤー」とコメントされて炎上。通報合戦になった。
- 利益計算をミスって、送料・手数料・返品で赤字。「思ったより儲からない…」
- ジャンク品を安く買って直したら売れた！と思ったら、別のジャンクを掴んで後悔。
- 在庫を抱えて資金がショート。結局損切りして「次は気をつけよう」と誓う。
- 公式が転売対策を発表した瞬間、出品が一気に消えて相場が大混乱。
- 中国輸入で検品不良・税関で止まって、商品が届かず顧客対応に追われる。
- 古物商なしで続けていたら、アカウント停止や警察沙汰の話を聞いて慌てて申請。
- トレンド商品を仕入れたのにブームが終わって、倉庫が不要品だらけに。

成功している人は、**リサーチに時間をかけ、在庫を抱えすぎず、法規制・規約をしっかり守る**傾向が強い。商材によってリスクの質がまったく違うので、資金力・知識・時間に合うジャンルから小さく始めるのが無難。

## ゲームへの落とし込み

この資料から、MVP（週1コマンド・48週）に足せるもの、β版以降で扱うものを整理した。実装状況は[ロードマップ](03_roadmap.md)の「追加調査からの反映候補」で管理する。

### 生活リズム
| 現実 | ゲームでの表現案 | MVPでの現状 |
| --- | --- | --- |
| 朝イチ発送が鉄則、遅れると評価ダウン | 週末の発送処理を「月曜の朝」の演出にする。体力が足りないと遅延 | 発送遅延→評価ダウンは実装済み。演出は未 |
| 月曜の発送地獄 | 週末（GW・12月など）に売れた分の発送体力を翌週の最初に請求する | 未 |
| 朝・昼・夜の三部構成 | 1週を「昼の行動（コマンド）」＋「夜の作業（出品・リサーチ・外注指示）」の2枠にする | **実装済み**（ステージ2から夜の作業。体力+5） |
| 車で県をまたぐ、ガソリン代・高速代 | 店舗せどりに「遠征」オプション（候補が増える代わりに交通費と体力） | 未 |
| 午後は疲れて判断ミス | 体力が低いと推定相場の誤差が広がる／偽物に気づきにくい | 未（体調不良率のみ） |
| 睡眠4〜6時間、深夜の電脳リサーチ | 「深夜の相場チェック」「寝不足」 | 実装済み |
| 腰痛・指の痛み | 「腱鞘炎」に加えて「腰痛」（店舗せどりの体力消費増） | **実装済み** |
| 在庫が生活空間を圧迫 | 部屋の容量と回復量の低下 | **実装済み**（レンタル倉庫・物流倉庫、置き場の限界） |
| 家族「いつまでやるの？」、週末の葛藤 | 家族の信頼度。週末に仕入れると下がり、ゼロで同居解消イベント | イベントは実装済み（信頼度は未） |
| 外注（指示・検品に時間） | 外注を雇う。休みの日は自分で全部やる | **実装済み**（外注3種・外注のお休み） |
| 価格改定ツール | 出品中の価格を毎週自動で相場に合わせる有料ツール（月額） | **実装済み** |
