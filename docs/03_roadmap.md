## フェーズ2：β版 — コンテンツ拡充

### 販路と仕入れ
- [ ] **アマクリ（大手EC・倉庫委託）**：月額料金、納品作業、梱包の体力が不要、真贋調査で請求書を求められる（せどり品は出せずに停止リスク）
- [ ] **専門マーケット**（スニーカー・トレカ）：鑑定つきで偽物リスクなし、手数料が高い
- [ ] **輸出**（マルコ・ポーロ／坂本龍馬のイベントで解禁）：国内で余っている品を海外で売る。為替と送料
- [ ] **買取業者**：すぐ現金化できるが安い（資金繰りの逃げ道）
- [ ] 店舗の「地図」：店ごとの値引きの曜日・クセを覚えていく（伊能忠敬の金特と連動）

### 商品
- [ ] 商品を40種以上に（MCHのエクステンションは1,797件）。シリーズ単位で世代交代（新作→旧作の値崩れ）
- [ ] **Rep（レプリカ）レアリティを「再販版」として表示**：再販が決まると同じ商品のRep画像が店頭に並ぶ
- [ ] 一番くじ風のくじ引き（A賞狙いで大量に引き、下位賞がダブつく）
- [ ] 医薬品・チケットなど「そもそも売ってはいけない」商品の誤出品イベント

### 仲間・イベント
- [ ] 仲間キャラを20人以上に。各3〜4段階の連続イベントと金特
  - 候補：渋沢栄一的な「合本主義」の人物、エジソン（自社製品を作る＝メーカー側に回る）、徳川家康（鳴くまで待つ＝長期保有）、ダ・ヴィンチ（真贋鑑定）、ナポレオン（兵站＝在庫管理）
- [ ] ライバル転売ヤー（MCHヒーローではなく、エネミーやオリジナルで）：同じ商品を狙って相場を崩してくる
- [ ] 家族・友人との関係値（部屋の段ボール、名義貸し、借金の告白）
- [ ] トラブルを**MCHのバトル演出**で表現：クレーマーとの「交渉バトル」（MCHのバトルエフェクト・カットインを流用）

### 周回要素
- [ ] 「転売屋カード」：1周ごとに完成した転売屋（能力・特殊能力）を保存し、2周目以降に「師匠」として呼べる（パワプロの選手保存・継承）
- [ ] 実績（アチーブメント）：「再販前に全部売り抜けた」「偽物を一度もつかまなかった」「サンタに譲った」など
- [ ] エンディング回収率

## 技術方針

| 項目 | 方針 |
| --- | --- |
| 構成 | ビルド不要の静的サイト（HTML + ES Modules + CSS）。Vercel にそのままデプロイできる（`vercel.json`） |
| ロジックと表示の分離 | `src/engine/` は DOM に依存しない純粋なロジック。`src/ui/` が描画。エンジンは「演出ステップ（steps）」の配列を返し、UI が順に再生する |
| データ駆動 | 商品・特殊能力・キャラ・イベント・トラブルは `src/data/` に集約。追加はデータを書くだけ |
| 乱数 | シード付き乱数をセーブデータに含める。同じシードなら同じ展開（テスト・デイリーチャレンジ用） |
| テスト | `node --test`。データの整合性、経済ルール、決定性、自動プレイでの48週完走 |
| バランス調整 | `test/bot.js` のヘッドレス自動プレイで統計を取る（`npm run balance`） |
| アセット | `tools/import_assets.py` が `mycryptoheroes` から必要な分だけコピー。一覧は `tools/assets.json` |
| 将来の移行 | 規模が大きくなったら TypeScript + Vite へ。エンジンは型付けしやすい純粋関数中心で書いている |
