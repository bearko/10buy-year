## フェーズ2：β版 — コンテンツ拡充

### 2周目以降のルート（キャリアの別の道）
- [ ] **商材特化ルート**：トレカ専門・ブランド専門など。特定ジャンルの目利きが突出して伸び、他ジャンルに弱い
- [ ] **組織型ルート**：並び屋・外注を早くから使って一気に規模を取る。炎上・規約違反のリスクが高い
- [ ] **継承**：1周目の転売屋（能力・スキル）を保存し、2周目以降に「師匠」として呼べる
- [ ] 実績（アチーブメント）とエンディング回収率

### 販路と仕入れ
- [ ] **専門マーケット**（スニーカー・トレカ）：鑑定つきで偽物リスクなし、手数料が高い
- [ ] **輸出**（マルコ・ポーロのイベントで解禁）：国内で余っている品を海外で売る。為替と送料
- [ ] **中国輸入**：為替・検品不良・税関で止まる
- [ ] 店舗せどりの遠征（交通費・体力と引き換えに候補増）、店ごとのクセを覚える「地図」

### 商品
- [ ] 商品を40種以上に（MCHのエクステンションは1,797件）。シリーズ単位で世代交代
- [ ] **Rep（レプリカ）レアリティを「再販版」として表示**：再販が決まると同じ商品のRep画像が店頭に並ぶ
- [ ] 季節商品の拡充：母の日・父の日・お中元、扇風機・冷感グッズ、ハロウィン、赤本、新生活家電
- [ ] スニーカーのサイズ属性（人気／不人気サイズ、サイズ違い返品）
- [ ] ジャンク品（不動品リスクと修理）、トレカのサーチ済みパック
- [ ] 一番くじ風のくじ引き（A賞狙いで大量に引き、下位賞がダブつく）
- [ ] 医薬品・コスメ（薬機法）など「売ってはいけない・売り方に注意がいる」商品

### 仲間・イベント
- [ ] 仲間キャラを20人以上に。各3〜4段階の連続イベントと偉人の奥義
  - 候補：エジソン（自社製品を作る＝メーカー側に回る）、徳川家康（鳴くまで待つ＝長期保有）、ダ・ヴィンチ（真贋鑑定）、ナポレオン（兵站＝在庫管理）
- [ ] ライバル転売ヤー（エネミーやオリジナルで）：同じ商品を狙って相場を崩してくる
- [ ] ステージ4〜5のイベントを厚く：外注の採用と育成、税務調査、事業売却の打診
- [ ] トラブルを**MCHのバトル演出**で表現：クレーマーとの「交渉バトル」（バトルエフェクト・カットインを流用）

## 技術方針

| 項目 | 方針 |
| --- | --- |
| 構成 | ビルド不要の静的サイト（HTML + ES Modules + CSS）。Vercel にそのままデプロイできる（`vercel.json`） |
| ロジックと表示の分離 | `src/engine/` は DOM に依存しない純粋なロジック。`src/ui/` が描画。エンジンは「演出ステップ（steps）」の配列を返し、UI が順に再生する |
| データ駆動 | 商品・スキルツリー・キャラ・イベント・トラブルは `src/data/` に集約。追加はデータを書くだけ |
| 乱数 | シード付き乱数をセーブデータに含める。同じシードなら同じ展開（テスト・デイリーチャレンジ用） |
| テスト | `node --test`。データの整合性、経済ルール、チュートリアル・ツリー・ステージ、決定性、実在ゲーム名の混入チェック、自動プレイでの10年完走 |
| バランス調整 | `test/bot.js` のヘッドレス自動プレイで統計を取る（`npm run balance`。ステージ到達時期と最終資産） |
| アセット | `tools/import_assets.py` が `mycryptoheroes` から必要な分だけコピー。一覧は `tools/assets.json` |
| 将来の移行 | 規模が大きくなったら TypeScript + Vite へ。エンジンは型付けしやすい純粋関数中心で書いている |
