# 18. 序盤の手ざわり（はじめての人が最初の 1 個を売るまで）

## なぜ

bearko.games ポータルの計測（2026-10）で、10 buy year！ を始めた 11 人のうち 7 人が 2 週目までに離れていた。全員 5 分以内で、8 人はスマホだった。他の作品と比べても、最初の節目（最初の売上）に届く人の割合が低い（2/6）。

自動で序盤を遊ばせると（`はじめから` から矢印のとおりに押す。390×844 のスマホ画面）、最初の売上まで **60 回押して 31 秒**かかっていた。そのうち 30 回ほどは、何かを選ぶ前の会話と画面だった。

- 難易度を選ぶ画面が、何も知らないうちに出る
- プロローグが 17 行ある（借金を背負うまでの経緯）
- 行動のカードを 1 回押すと矢印が消え、小さい「決定」だけが残る（2 回押すことが分からない）
- 出品の画面に、絞り込み・並べ替え・一括操作・即決買取・選択が並んでいる
- 出品したあと、次に押す場所（閉じる）を指していない。矢印は次の出品ボタンを指し続ける

## 何を変えたか

| | 前 | 後 |
|---|---|---|
| 難易度 | 毎回選ぶ | **はじめての人は「ふつう」で始まる**。選びたい人はタイトルの小さい「難易度を選んで始める」から。2 回目からは今までどおり選ぶ |
| プロローグ | 17 行 | **はじめての人は 10 行の短い版**（`prologueShort`）。借金・最初の一手・返済の条件（3 か月払えなければアウト）は残す |
| 省いた経緯 | — | スキルツリーを初めて開いたとき（ミッション `tree_root` の報酬）に、回想として 3 行で出す（`backstory`）。見たら `s.flags.backstoryShown` |
| 行動のカード | 選ぶと矢印が消える | **選んでも矢印を残す**。案内中は、説明に「▶ もう一度押すと決定」を足す |
| 最初の出品 | すべての道具が並ぶ | ミッション `list_home` のあいだは**出品ボタンと値付けだけ**（`.inv-simple`）。2 回目の出品からは全部出る |
| 出品のあと | 次の出品ボタンを指す | **「閉じる」を指す**（`list_home` / `list_bought` を済ませたあと・`sell_home` のあいだ） |

「はじめての人」＝ このブラウザでプロローグを見ていない（`10buy-year:prologueSeen` がない）かつ、ランキングに記録がない。

一度見た人の流れは変えていない（「スキップして始める／プロローグを見る」を選ぶ。全部見たか前に見ていれば回想は出さない）。今週・今日のチャレンジも、今までどおり難易度を選ばずに始まる。

## 結果（自動プレイ・同じ手順）

| | 前 | 後 |
|---|---|---|
| 最初の出品まで | 35 回・17.4 秒 | **18 回・9.6 秒** |
| 最初の売上まで | 60 回・31.2 秒 | **39 回・21.2 秒** |

実際の人の離れ方は、プレイログ（[docs/16_play_telemetry.md](16_play_telemetry.md)）と共通基盤のポータル計測で、公開のあとに見比べる。

## 残っていること

- 会話のあいだも、下の行動カードに前の矢印が残って見える（会話が終わると正しい場所に移る）。前からある
- 最初の画面の数字（借金・体力・評価・TOKU など）の多さは、まだ手をつけていない
