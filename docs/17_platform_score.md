# 17. bearko.games 共通基盤の総合スコア・アチーブメント・RTA

bearko.games の総合スコア（[bearko/mycryptoportfolio の SPEC-002](https://github.com/bearko/mycryptoportfolio/blob/claude/game-portfolio-page-4afqbc/docs/specs/SPEC-002-total-score.md) 3.8）と、アチーブメント（SPEC-001 9.4・SPEC-008。旧トロフィー）に参加する。

- エンディング（`showEnding`）で 1 回だけ、成績を共通基盤の SDK で送る。点の計算は共通基盤のサーバー
- 送る成績：`years`（遊び切った年数。10 年なら 10）、`netWorth`（純資産）、`difficulty`（easy / normal / hard）、`ending`（エンディングの ID。`exit` は事業売却）・`daily`・`weekly`、`legacy`（前の周から継承したスキルの ID。なければ `null`）・`mentor`（師匠がついたか）
- 点（**v2**。2026-10-18 から。決め方は下の「v2 の係数の根拠」）：
  - 10 年遊び切る、または事業売却で引退する（`ending: 'exit'`）と、1,000 ＋ 純資産 ÷ 5,555 × 難易度の係数 × 継承の係数
  - 途中で終わったら（破産・失踪・逮捕など）、年数 × 100 ＋ その成績の 3 割
  - 難易度の係数：やさしい 0.9 ／ ふつう 1.0 ／ きびしい 1.3
  - 継承の係数：継承なし・師匠なし 1.0 ／ 師匠だけ 0.8 ／ 継承スキルあり 0.7（総合商社 `cap_trade` 0.45 ・裏社会の帝王 `cap_dark` 0.5）
- SDK（`https://bearko.games/sdk/v1.js`）が読めない・通信に失敗しても何もしない（`src/platform.js`）。自己ベスト更新の通知とログインの案内は SDK が出す

### v2 の係数の根拠（自動プレイ 2,160 周。2026-10-18）

v1 には次の問題があった（issue #7 / #8 / #10）。遊んだ記録（テレメトリ）はまだ少ないので、`test/bot.js` の自動プレイで係数を決めた。

- 事業売却（9 年目まで）で引退した周が「途中で終わった」扱いになり、1,000 点の土台がもらえなかった → クリア扱いにした
- 難易度の係数（v1 は 0.7 / 1.4）が、実際の稼ぎの差と合っていなかった。自己ベスト（3 回のうち最高）の純資産は、やさしいがふつうとほぼ同じ（ふつう ÷ やさしい ＝ 0.99）、きびしいがふつうの約 8 割（ふつう ÷ きびしい ＝ 1.28）。v1 はやさしいを下げすぎ、きびしいを上げすぎていた → 0.9 ／ 1.3（きびしいほうが少しだけ得）
- 継承スキル・師匠つきの周は純資産がふつうの 1.25〜1.6 倍になり、継承するほど点が伸びた → 係数で打ち消す。総合商社と裏社会の帝王は特に強い（約 2〜2.2 倍）ので低い係数にした
- 途中で終わった周の成績の割合は、0.5 以下なら「わざと途中でやめたほうが得」にならなかった → 0.3
- 総合商社・裏社会の帝王がゲームの中で強すぎることは、ゲーム側の調整の課題として残す

## RTA（SPEC-001 6.18。レギュレーション `10buy-stage5`）

- タイトルの「⏱ RTA で挑む」で、**今週のチャレンジ**（週ごとのシード・ふつう・継承なし・師匠なし・キャリアの型なし）を RTA の計測つきで始める。SDK が読めないときはボタンを出さない
- 区切り：ステージ 2 → `stage2`、3 → `stage3`、4 → `stage4`、5 → `clear`。上がった週（`s.stageWeeks`）を `igtMs` の欄にそのまま入れる。**順位はステージ 5 に着いた週の少ない順**（同じ週なら実時間）
- 共通基盤は区切りごとの最小の週（7 ／ 11 ／ 47 ／ 51 週）を下回る記録と、週が前の区切りより減った記録をはじく
- ステージ 5 より前のゲームオーバー・事業売却、タイトルに戻る、つづきから、別のプレイを始めるときは中断する。計測はページの中だけで持つので、再読み込みすると消える
- 実装は `rtaStart` ／ `rtaProgress`（週のはじめと週の終わり）／ `rtaAbort`（`src/platform.js`）
- 自動プレイ（ふつう・継承なし 60 本）：ステージ 5 に着いたのは 67%、中央値 391 週・最短 315 週

### 送り方

- 判定は `earnedTrophies`（純関数）、送るのは `reportTrophies`（`src/platform.js`）。**セーブに残る値だけで判定する**ので、前から遊んでいる人にも次の週のはじめに付く。新しい保存項目は足さない
- 呼ぶところ：週のはじめ（セーブの前）・エンディング（`showEnding`）・美術画廊でコレクションを買った瞬間（手放すと `s.collection` から消えるので、その場でも送る）
- 未ログインの最初の書き込みで仮アカウントができるので、**1 つずつ順に送る**（前の返事を待ってから次を送る）
- 送ったものはセーブ（`s.trophies`）に覚えて、同じプレイでは送り直さない。さらに同じ起動（ページ）の中で送れた ID は、別のプレイを始めても送り直さない。通信に失敗したら次の機会に送り直す。通知は SDK が出す
- 継承の周・難易度・デイリー／週替わりチャレンジ・RTA で区別しない（作者の決定 2026-10-17）
- ゲームの画面にアチーブメントの名前は出していない（実績の画面はゲーム内の実績 `src/engine/achievements.js` で、別のもの）
- 共通基盤が新しい ID を公開するまでは、知らない ID として 400 ではじかれる（遊びには影響しない。次の機会に送り直す）
