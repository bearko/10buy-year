# 15 UI・操作・演出の改善提案（没入感と満足感）

ゲームの中身（商品・イベント・数値バランス・仕組み）には手を入れず、**UI・操作ステップ・レイアウト・演出**だけで、遊んでいる手ざわりと「やった」という手応えを上げるための洗い出し。
最後に、効果と工数から優先度をつけた実装順を置く。

## 1. 調べ方

- スマホ相当のブラウザ（412×915・390×844・360×740・375×667）で、実際に遊んで記録した。
  - タイトル → 難易度 → プロローグ → チュートリアル → 1年目の4〜5月（8週）
  - 4年目（ステージ3）のセーブから2週（店舗巡り・夜の作業・週末）
  - 10年目の最終週のセーブから、エンディングまで
  - 中盤の画面はすべて開いた（在庫・ミッション・メニューの各画面・スキルツリー・基礎能力・ログ・夜のスマホ）
- 画面写真・タップ数・流れたメッセージを自動で記録し、気になった点はコードで裏づけた。
- 自動プレイの遊び方：店舗巡りは1回に2〜3店、各店で売り場を2か所見て1品買う。仕入れ後の「すぐ出品する？」は出品する。タップ数はこの遊び方での値（人が遊ぶと増減する）。

## 2. いまの強み（残す・伸ばす）

- **画面の中の道具がそのままUI**：夜のスマホ（ロック画面の時計・通知・アプリ・タブバー）、売れた知らせのメール、店の見取り図と客・店員・同業者、部屋に積まれる在庫と発送の段ボール。ここは他の改善でも崩さない。
- **セリフの色分けと用語の解説**（金額・ゲームの言葉・専門用語）。
- **スキルツリーの解放演出**、基礎能力のランクアップ演出、交渉成功率の円ゲージ。
- ドット絵をドットのまま見せる表示。

## 3. この提案の原則

1. **タップを増やさない**：新しい演出は、待たせない・止めない（タップ不要、0.8秒以内、タップで飛ばせる）。これまでのフィードバック（トラブル演出を控えめに）と同じ方向。
2. **判断する場所に、判断の材料を**：別のタブや別の画面に行かないと分からない数字を、決める瞬間の目の前に出す。
3. **手応えはHUDとステージで**：画面全体を覆うポップアップより、所持金・ゲージ・クリスの表情で返す。
4. **モーダルを増やさない**：同じ内容を何度も見せる流れは1つにまとめる。
5. `prefers-reduced-motion` と文字サイズ設定は、新しい演出でも守る。

## 4. 改善点の一覧

工数の目安：S＝半日まで、M＝1〜2日、L＝3日以上。

### A. テンポ・操作ステップ（480週くり返すので、1タップの差が大きい）

**A1. 週末の「メール → 取引結果 → 発送」を1本の流れに**（M）
- 現状：受信トレイ（「まとめて確認する」）→ 取引結果の一覧（OK）→ 発送の演出、と同じ売上を3回見る。結果一覧の合計は一番下にあり、売れた数が多いと見えない。
- 提案：メールは「通知が落ちてくる」演出だけにして自動で流し、続く1枚の「週末レポート」の上に **今週の利益・件数・いちばん儲かった品** を大きく出す。一覧は折りたたみ、発送の演出はそのレポートの後ろ（ステージ）で自動で流す。発送が遅れた品の注意は、1件ずつではなく「3件の発送が遅れた」とまとめる。
- 効果：毎週1〜2タップ減。結果が一目でわかる。

**A2. 週明け・月末のお知らせをダイジェスト1枚に**（M）
- 現状：入金・予約品の到着・寝不足・長期在庫レポート・カード引き落とし・返済などが、1つずつメッセージ欄に出て、それぞれタップが要る。
- 提案：会話（キャラのセリフ）ではない連続したお知らせは、アイコンつきの行をまとめた1枚にする（良い知らせ・悪い知らせで色分け）。会話はこれまでどおり1行ずつ。
- 効果：週明けのタップが半分ほどに。何が起きたかを一覧で見られる。

**A3. 「出品枠が空いています」を、流れを止めない形に**（S）
- 現状：週の最後の行動を決めるとき、未出品の在庫と出品枠のあきがあると確認ダイアログが出る（今回の自動プレイでは、チュートリアル期の8週で5回）。チュートリアルの案内が「店舗せどり」を指しているのに、決めると「先に出品して」と言われる食い違いもある（家の中を探して見つけた品が未出品のとき）。
- 提案：ダイアログをやめ、行動カードの上に「出品枠あき5・未出品3 → 先に出品」の帯を出す（タップで在庫画面）。チュートリアルの案内中は出さない。
- 効果：毎週の中断が消え、案内と食い違わない。

**A4. プロローグと一度見た会話のスキップ**（S）
- 現状：はじめからの度に、プロローグ16行を1行ずつ送る。今日・今週のチャレンジでも毎回同じ。
- 提案：一度最後まで見たら（実績の記録に残す）、プロローグの右上に「スキップ」を出す。
- 効果：2周目・チャレンジの立ち上がりが20タップ → 4タップ。

**A5. テキストのオート送りと早送り**（S）
- 現状：送りはタップのみ。文字の速さは変えられるが、オートと早送りがない。
- 提案：メッセージ欄の右下に「AUTO」の切り替え、長押しで早送り（選択肢・お知らせの手前で止まる）。
- 効果：片手でも読み流せる。長い会話イベントのストレスが減る。

**A6. 店舗巡りの手数を減らす**（M）
- 現状：1店で「売り場を選ぶ → 品を開く → カゴ → 戻る → レジ → 次の店へ」と10タップ前後。
- 提案：
  - 「残りの売り場を全部見る」ボタン（時間が足りる分だけ、続けてガサゴソの演出）。
  - 見つけた品のカードに「＋カゴ」の小ボタン（商品ページを開かずに入れられる）。
  - カゴに品があるときは「レジで払って次の店へ」を1つのボタンに（いまは レジ → レシート → 次の店へ の2段階。カゴに品があるまま帰ろうとすると、トーストで止まる）。
- 効果：店舗巡り1回あたり3〜6タップ減。「探す・選ぶ」の気持ちいいところだけが残る。

**A7. 仕入れ直後の連鎖を1画面に**（M）
- 現状：仕入れた品のカード（タップで送る）→「すぐ出品する？」と、2段階。
- 提案：「すぐ出品する？」の画面の上に、仕入れた品の絵を並べる（獲得カードの役目を兼ねる）。
- 効果：仕入れのたびに1タップ減。手に入れた喜びと出品の判断が同じ画面で完結する。

**A8. 行動カードの「選んで → 決定」を、慣れた人は1タップに**（S）
- 現状：1回目のタップで選択（予告が出る）、2回目で決定。
- 提案：設定で「1タップで決定」を選べるようにし、長押しで予告だけ見られるようにする。初めての人は今のまま。

### B. 判断のしやすさ（情報を、判断する場所に）

**B1. 商品ページの上に「判断の帯」**（S）
- 現状：商品ページを開くと、値札の下は「商品の情報」（カテゴリ・状態）が既定のタブで、見立て・相場との比較・見込み利益は3つめの「自分のメモ」タブにある。一覧のカードには小さく見立てが出るだけ。
- 提案：値段のすぐ下に「見立て ¥3,810（値段は見立ての62%）／見込み利益 +¥1,050」の帯を常に出す。利益計算のスキルがないうちは「見込み利益 ？」のまま（スキルの価値も伝わる）。売れた値段を調べたら、帯の見立てがその値に置きかわる。
- 効果：転売の一番気持ちいい「目利き」の瞬間が、毎回目の前で起きる。仕入れのたびに効く。

**B2. 行動を選んだときの経験点の予告が見えない（前回の変更による退行）**（S）
- 現状：右の欄を「基礎能力」表示にしたため、行動を選んでも「行動 +7・情報 +3」の予告が出ない（経験点のタブに切り替えると出る）。
- 提案：予告中は、基礎能力の表示のまま下に「この行動で：行動+7 情報+3 対人+1」の行を出す。または予告中だけ経験点の表示に切り替える。
- 効果：行動選びの判断材料が戻る。

**B3. 行動カードに体力・お金の目安を常に出す**（S）
- 現状：体力の消費や費用は、カードを1回タップして予告を見るまで分からない。
- 提案：カードの右下に「体力-15」「¥6,000」の小さな数字（危ないときは色）。

**B4. HUDの項目をタップで説明**（S）
- 現状：評価・TOKU・やる気・Stage・目標の説明は `title` 属性だけで、スマホでは見られない。
- 提案：タップで小さな吹き出し（いまの値・何に効くか・上げ下げの理由）。「評価 91（先週 -9：発送遅れ3件）」のように、直近の変化の理由も出す。

**B5. 在庫画面のコンパクト表示・並べ替え・絞り込み**（M）
- 現状：1つの品に値付けと個数のスライダー・2つのボタンが並ぶ大きなカード。終盤の67点では長い。
- 提案：1行1品のコンパクト表示（タップで今のカードに広がる）、並べ替え（見込み利益・在庫日数・相場との差）、絞り込み（未出品・出品中・90日以上）。

**B6. 相場画面を短く**（M）
- 現状：ニュースと全商品の相場カードが1列に続き、8.3画面分ある。
- 提案：タブ（ニュース／持っている品／すべて）と、並べ替え（値上がり・値下がり順）。持っている品の上がり下がりを先に見せる。

**B7. メニューの整理**（S）
- 現状：相場・経営・業界の動き…とゲームの機能の下に、サウンド・言語・文字の大きさ・文字送り・取引の対応・通知のON/OFF・タイトルへ、が同じ画面に並ぶ。
- 提案：設定は「⚙ 設定」にまとめて別画面に。機能は「お金と事業」「人と世界」「記録」で見出しを分ける。

**B8. 用語集と遊び方を、いつでも見られる場所に**（M）
- 現状：用語の解説はログの中でセリフの下に出るだけ。遊び方を後から読み返す場所がない。
- 提案：メニューに「用語集」（いまある用語データの一覧）と「遊び方」（チュートリアルの要点）。セリフの中の色つきの用語をタップしたら、その場で解説を出す。

### C. 手応え・報酬の演出（止めずに、HUDとステージで）

**C1. お金の増減に手応えを**（S）
- 現状：所持金・借金は数字が切りかわるだけ。
- 提案：入金・支払いのとき、数字が0.5秒でカウントアップ・ダウンし、横に「+67,240」が浮いて消える。借金が減ったときは借金の数字が光る。
- 効果：毎週の入金・月末の返済が、毎回うれしくなる。タップは増えない。

**C2. 月次決算をカードで**（M）
- 現状：月末は「5月の締め：純利益 27,619円（売上 83,875円・9個）」の文字だけ。目標との差は上のHUDを見ないと分からない。
- 提案：1枚のカードに、今月の純利益と目標のゲージ（貯まっていく演出）、連続達成の数（2か月中1か月）、先月との比較、借金の残り（150万円からの進み具合のバー）、今月のベスト商品。
- 効果：月ごとの区切りが「1つの章が終わった」感覚になる（10年で120回）。

**C3. 自己ベスト・初めての達成のスタンプ**（S〜M）
- 提案：取引結果の中で「過去最高益」「初めて10万円で売れた」「最短で売れた」に小さなスタンプ。いまある記録（成績・実績）から出すだけ。

**C4. クリスの表情を結果に合わせる**（S）
- 提案：大きく売れた週・入金はガッツポーズ、赤字の月・トラブルの決裂はしょんぼり、など既存のポーズを結果に合わせて1〜2秒だけ切りかえる。

**C5. ステージ到達のときに「できるようになったこと」を見せる**（M）
- 現状：「スキルツリーで新しいパネルを解放できるようになった」とだけ出る。
- 提案：到達の演出のあとに、増えた行動・開いたメニュー・夜の行動などを、アイコンつきで並べる（そのステージで開いたものを数えるだけ）。

**C6. 段階的な開放（鍵を見せずに、開いたときにお披露目）**（M）
- 現状：1週目から🔒のボタンが3つ並び、右の欄は全部「F 20」。始めたばかりの画面の情報が多い。
- 提案：使えないボタンは出さず、開いた瞬間に「NEW」で光って現れる。チュートリアル中はニュースの帯も止める。
- 効果：最初の画面が軽くなり、機能が増えること自体がご褒美になる。

### D. 時間の流れ・世界の手ざわり

**D1. 週替わりの日めくり**（M）
- 現状：週が変わってもHUDの日付が変わるだけ。
- 提案：0.6秒の日めくり（「5月 第2週」、月が変わるときは月の名前を大きく）。タップ不要・飛ばせる。月替わりは C2 の決算カードにつなぐ。

**D2. 季節と夜の画面演出（CSSだけ）**（M）
- 提案：ステージに季節の重ね（春は花びら、夏は強い光、秋は落ち葉、冬は雪がちらつく）と、夜の行動のときの夜の色味。画像を増やさず、CSSの色と粒で。動きを減らす設定では止める。
- 効果：10年の時間が「目で見て」流れる。

**D3. 年末の「1年のまとめ」をカードとグラフに**（M）
- 現状：年末のまとめは文字のお知らせ。
- 提案：12か月の利益の棒グラフ、去年との比較、その年に到達したステージ・出会った人を1枚に。

**D4. BGMの使い分けとフェード**（S）
- 現状：5曲を場面で切りかえている（曲の切りかえは即時）。
- 提案：いまの5曲の割り当てを見直し（夜の行動・月末・年末など）、切りかえを1秒のフェードに。

### E. レイアウト・操作感

**E1. 縦長スマホで、行動カードを画面の下（親指の位置）に**（S〜M）
- 現状：ステージの高さが最大324pxで止まり、412×915では行動カードの下に229px（25%）の空きがある。親指が届きやすい場所に何もなく、押す場所は画面の中ほど。
- 提案：行動カードを画面下に寄せ（下端の安全域を空ける）、空いた高さはステージとメッセージ欄に回す。
- 効果：片手で遊びやすくなり、ステージ（キャラと部屋）が大きく見える。すべての画面に効く。
- 追記：最初の版はアドレスバーのない高さを前提にしていて、ブラウザで遊ぶと行動カードが画面の外に出た。ステージの高さを「画面 − 上の情報 − メッセージ欄 − 行動カード」から実際に測って決める形（`ui/layout.js`）に直し、行動が7つ以上の分類はカードを横長に詰める。クリスの大きさは230pxまで。

**E2. ホーム画面に追加してフルスクリーンで遊べるように（PWA）**（M）
- 現状：スマホのブラウザでは、上のアドレスバーなどが画面の1割ほどを使っている。
- 提案：Webアプリのマニフェスト（名前・アイコン・全画面表示）を置き、タイトルに「ホーム画面に追加」の案内。アイコンはいまある画像から作る。
- 効果：アプリのように全画面で遊べ、没入感が大きく上がる。

**E3. Androidの戻る操作と、セーブのタイミング**（M）
- 現状：戻る操作（ジェスチャー）に対応しておらず、開いている画面を閉じる代わりにページから出てしまう。セーブは週のはじめだけなので、週の途中で出たりアプリを切り替えてタブが閉じられると、その週の仕入れなどが消える。
- 提案：画面を開くときに履歴を1つ積み、戻る操作でその画面を閉じる。行動が終わるごとと、アプリを切り替えたとき（`pagehide`・`visibilitychange`）にもセーブする。
- 効果：誤操作で進行を失うことがなくなる（スマホでいちばん悔しい体験を防ぐ）。

**E4. トーストの重なり**（S）
- 現状：トーストは画面下に1つずつ出て、続けて出ると重なる。
- 提案：縦に積み、仕入れ画面などの下のボタンと重ならない位置に。

**E5. タイトル画面のボタン整理**（S）
- 現状：8〜9個のボタンが縦に並び、スクロールが要る。
- 提案：「つづきから／はじめから」を大きく、チャレンジ2つを横並び、ランキング・実績・このゲームについて・言語・サウンドは下に小さなアイコンの列。

### F. 続ける理由・ふり返り

**F1. 再開したときの「前回まで」カード**（S）
- 提案：「つづきから」で、いまの所持金・借金・目標の進み具合・先週の結果・進行中のミッションを1枚で見せてから始める。
- 効果：数日あけて遊んでも、すぐに状況を思い出せる。

**F2. エンディングのふり返り演出**（M〜L）
- 現状：エンディングの文・ランク・数字の表・実績が、一度に全部出る。主なボタンは「タイトルへ」。
- 提案：
  - 査定の順番に見せる（文 → 数字のカウントアップ → ランクのはんこ）。タップで飛ばせる。
  - 10年の月ごとの利益と純資産のグラフ（記録はすでに残っている）、名場面（初めて売れた日・完済した日・各ステージに上がった日・いちばん儲かった取引）。
  - 結果を画像のカードにして共有（文字だけの共有より広まりやすい）。
