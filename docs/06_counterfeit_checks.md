# せどりの偽物見極めポイントとゲームへの落とし込み

仕入れ画面（フリマ・通販・店舗）で「偽物かも」と直接書かずに、実際のせどりで偽物をつかむときの手がかりを再現するための資料。ゲーム内の実装は `src/engine/listing.js`（手がかりの生成）と `src/ui/shop.js`（画面）。

## 1. 仕入れルート（最も重要な変数）

| 評価ポイント | 安全寄り | 危険寄り | ゲームでの表現 |
| --- | --- | --- | --- |
| 信頼度 | 正規店・公式アウトレット・大手リサイクルショップ・鑑定付き買取店 | 個人フリマ、海外個人輸入、露店 | 販売元ごとに偽物の混入率が違う（店舗・公式 0、リサイクルショップ低、プンシー中、GLOBAL☆DEAL 高、業者オークションごく低） |
| 履歴の透明性 | 購入証明（レシート・箱・ギャランティ）が残っている | 「詳細不明」だけ | 付属品の欠品、説明文の具体性 |
| 価格乖離 | 相場の70〜110% | 相場の50%以下で「新品同様」 | 自分のメモ欄の「相場との比較」 |
| 出品者属性 | 評価が多い、悪い評価に「偽物」がない、同じ高額品を大量出品していない | 新規・評価10件未満・同じ高額品を短期間で大量出品 | 出品者カード（評価数・良い割合・本人確認・登録月数・同じ商品の出品数・最近の評価） |

## 2. 写真（ネット仕入れの生命線）

| 評価ポイント | 本物っぽい | 偽物っぽい | ゲームでの表現 |
| --- | --- | --- | --- |
| 撮影の質 | 出品者本人が多角度で撮影。タグ・縫い目・底・シリアルをアップで | 公式画像の流用、暗い、重要な部分を隠す | 写真の枚数・「SAMPLE」の透かし・写っていない部分 |
| 細部の鮮明さ | ロゴ・ステッチ・刻印がくっきり | 文字のにじみ、ロゴの形の違い | 細部チェック（目利きで見られる数が増える） |
| 付属品 | 箱・タグ・ギャランティが一緒に写る | 本体だけ | 商品の情報の「付属品」 |

巧妙な偽物（公式画像を加工、本物の箱に偽物を入れる）は、写真や出品者からは見分けにくい。ゲームでは「巧妙な偽物」は赤信号が本物並みにしか出ず、細部チェックでも半分ほどしか違和感が出ない。

## 3. 説明文と質問への対応

| 評価ポイント | 安全寄り | 危険寄り |
| --- | --- | --- |
| 具体性 | 購入時期・場所・付属品・傷の位置 | 「正規品です」「美品」だけ |
| 価格の理由 | 「付属品欠品のため安め」など合理的 | 「在庫処分」「即決希望」だけで異常に安い |
| 質問への対応 | 追加写真を送ってくる | 「本物です」の一点張り、返信なし、写真を拒否 |
| 表記 | 普通 | 「〇〇風」「ノーブランド」（それでも商標的に危うい） |

ゲームでは商品ページの「コメント」から1回だけ質問でき、足りない部分の写真をお願いできる。本物の出品者は多くの場合応じ、追加された写真の部分は細部チェックの対象になる。

## 4. 実物・写真の細部チェック（ジャンル別）

| ジャンル | 確認項目（ゲーム内） |
| --- | --- |
| スニーカー | 箱ラベルとタグの品番、ステッチの間隔、インソールのプリント、ソールの刻印 |
| 時計 | 裏蓋の刻印、文字盤の印字、シリアルの書体、重さと金具 |
| トレカBOX | シュリンク（メーカーロゴ入りか）、箱の印刷、底面の封 |
| フィギュア | 目の印刷の左右対称、塗装のはみ出し、メーカー刻印、箱の印刷 |
| お酒 | ラベルの紙質、キャップの封、液面の高さ |
| 家電 | 箱のシール、箱と本体のシリアルの一致、付属品が純正か |
| ジュエリー | ロゴと刻印（「O」の形）、金具の重量感とメッキ、ギャランティの書式 |
| 楽器 | 内部ラベルの年代、ニスの経年、木の質感 |

店舗・業者オークションでは手に取れるので全項目を確認できる。ネットでは写真に写っている部分だけ。

## 5. 見極めフローとゲームの操作

1. 相場を調べる → 自分のメモ欄の「推定相場」「相場との比較」
2. 出品者の評価・履歴を確認 → 出品者カード
3. 写真の質と細部を拡大チェック → 写真のサムネイル、細部チェック
4. 説明の具体性、追加写真のお願い → 商品の説明、コメント（質問）
5. 実物で素材・縫製・シリアルを確認 → 店舗・業者オークションの「手に取って見る」
6. 不安なら鑑定 → 到達点「鑑定士」（鑑定眼）

最終鉄則は「少しでも違和感があれば買わない」。偽物を売ると商標法違反のおそれがあり、ゲームでも返品・評価の低下・アカウント停止につながる。
