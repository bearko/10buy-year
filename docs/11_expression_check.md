# 表現チェック（フェーズ3）

公開前に、ゲーム内のテキストを「実在の名前」「法律・税金の説明の正確さ」の2点で見直した記録。
次に見直すときは、この表を上から確認し、結果を追記する。

## 1. 実在の名前

| 対象 | 方針 | チェック方法 |
| --- | --- | --- |
| 実在のゲームタイトル | 出さない | `npm test`「ゲーム内テキストに実在ゲーム・実在サービス・ブランドの名前を出さない」 |
| 販売サービス（フリマ・オークション・EC） | パロディ名（プンシー・ミィーム・アマクリ・ホンモノ堂・海外EC） | 同じテスト（メルカリ・ヤフオク・Amazon・eBay・StockX など） |
| 店・ブランド・キャラクター商品 | 架空の名前（ロンロン卸、ルビーくじ など） | 同じテスト（ドンキ・ブックオフ・ロレックス・ディズニー・一番くじ など） |
| 偉人（MCHのヒーロー） | MCHのヒーローとして登場させる。転売ヤーそのものにはしない | 目視（`docs/10_mch_review.md` の役どころ表） |

テストは `src/` と `index.html` の全文（コメントを含む）を見る。社内の識別子（`ch_miime` など小文字のID）は対象外。

## 2. 今回直したところ（2026年10月）

| 場所 | 前 | 後 | 理由 |
| --- | --- | --- | --- |
| 偽物をつかまされたイベント（`src/data/events.js`） | 「在庫から『即決買取』で処分するしかない」 | 「フリマでも買取店でも商標法違反。値段はつかないから『処分する』しかない」 | 偽物と知って買取店に売るのも商標法違反。買取額0円の「処分」と合わせた |
| チケット転売イベント | 「定価を超える転売は犯罪」 | 「転売禁止と書かれた公演チケットを、商売として定価より高く売るのは違反。1年以下の拘禁刑か100万円以下の罰金」 | 法律の対象（特定興行入場券・業として）と罰則を正確に。2025年6月から懲役は「拘禁刑」 |
| 用語解説「確定申告」 | 「副業の所得が年20万円を超えると必要」 | 会社員と専業で条件が違うこと、20万円以下でも住民税の申告はいることを追記 | 20万円ルールは給与所得者の副業だけの話 |
| 用語解説「薬機法」 | 「化粧品やサプリは効能をうたえない」 | 化粧品は認められた範囲を超える効能、サプリは医薬品のような効能をうたえない | 化粧品は一定の効能表示が認められている |
| 用語解説（追加） | なし | 「ステマ」「商標法」 | 作中に出てくるのに説明がなかった |
| 所得税の計算（`src/engine/finance.js`） | 最高税率50% | 4,000万円超を55%に | 所得税45%＋住民税10% |
| 難易度「きびしい」 | 借金250万円・年利18% | 年利15%・最低返済 月4.5万円 | 利息制限法の上限は元本100万円以上で年15% |
| くじのコマンド説明 | 「一番くじ風」 | 「等級つきのキャラクターくじ」 | 「一番くじ」は登録商標 |

## 3. 見直して、そのままにしたところ

| 内容 | 判断 |
| --- | --- |
| 古物商許可：警察署で申請・手数料19,000円・約6週間（`commands.js`） | 正しい（標準処理期間は40日程度） |
| 「個人から買った未使用品も古物」（`events.js`） | 正しい（一度でも使用のために取引された品は古物） |
| 盗品：古物商の確認義務 | 正しい（古物営業法の本人確認・不正品の申告義務） |
| 酒類：継続して売るには酒類販売業免許。通信販売酒類小売業免許の登録免許税3万円 | 正しい |
| カラコンは高度管理医療機器で、販売には許可がいる | 正しい |
| 法人：均等割7万円 | 正しい（最低額。資本金・従業員数で上がる） |
| 法人税の実効税率25% | 簡略化（実際は所得の額や自治体によっておよそ20〜35%）。ゲーム上の数字として注記済み |
| 関税・輸入消費税をまとめて10% | 簡略化（品目で大きく変わる）。ゲーム上の数字として注記済み |
| 手数料（プンシー10%など） | 架空のサービスの数字。実在サービスに近い水準を参考にした |

## 4. 表現のトーン

`docs/02_game_design.md` 11章（真剣に・貶めない・違法は違法・偉人は偉人として・笑いで刺す・実名を出さない）に沿っているかを、イベントの文面で確認した。違法な選択（チケット高額転売・盗品・偽物・無申告・ステマ）には、どれもゲーム上の罰か炎上がある。
