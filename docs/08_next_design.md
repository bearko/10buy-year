# 後半の遊びを変える拡張の設計（プレイフィードバック第3弾）

後半（ステージ4〜5）がパターン化して「数字が勝手に増えるだけ」になる問題に対して、5つのトピックのゲームロジックを設計したもの。
5つは独立した機能ではなく、**「稼ぎ方が変わり続ける世界」** という1本の柱でつながるように作る。

| # | トピック | ひとことで | 規模 |
| --- | --- | --- | --- |
| 1 | 後半の動機づけ | お金以外の「志（こころざし）」と、年ごとの大事件 | 大 |
| 2 | ✅ 販売方式・法律の変化（いたちごっこ）（実装済み） | 稼いでいる商材ほど規制・対策の標的になる | 大 |
| 3 | ✅ 商材・顧客によるキャリアパス（実装済み） | 顧客層を育てると、KOL・鑑定士などに転身できる | 大 |
| 4 | ✅ 儲けを消費するルート（百貨店・外商・コレクションは実装済み） | 使ったお金が、外商・人脈・コレクションとして返ってくる | 中 |
| 5 | ✅ vs 他の転売屋（飽和）（実装済み） | 仕入れ先は荒らされる。開拓し続けないと枯れる | 中 |
| — | マイクリ資産の活用 | 404人のヒーロー・499体のエネミー・1,797点のエクステンションを使い切る | — |

この設計と同時に、次の4つは実装済み（[03_roadmap.md](03_roadmap.md)）：オープニングの曲の切り替え、出品枠の空きの通知、**仕入れルートの開拓**（トピック5の土台）、**経験点の振り替え**。

## 0. いまの後半がつまらない理由（診断）

| 原因 | 起きていること |
| --- | --- |
| 最適解が固定 | 一度うまく回る仕入れ→出品の型ができると、10年目まで同じ型が通用する |
| ルーティンが強すぎる | 型を自動で回せるので、考える場面がなくなる |
| お金の使い道がない | 稼いだお金は純資産の数字になるだけ。使うと損をする |
| 目標が金額だけ | ステージ5は「純資産◯円」。物語がなく、増やす意味を感じない |
| 敵がいない | 相場は変わるが、自分の行動に反応する相手がいない |

→ **型を壊すもの（2・5）**、**お金に意味を与えるもの（3・4）**、**それらを物語にするもの（1）** を足す。

## 1. 後半の動機づけ：「志」と「業界の年表」

### 1.1 志（こころざし）を選ぶ
- ステージ4に上がったとき（法人化）、マインと龍馬との会話で **志** を1つ選ぶ。あとから一度だけ変えられる（「志を変える」イベント、年1回まで）。
- 志ごとに **3段の目標（マイルストーン）** と専用のイベント・エンディングがある。HUD の目標欄は、純資産ではなく志の目標を出す（純資産は最終査定に残る）。

| 志 | 内容 | 目標（例） | 関連 |
| --- | --- | --- | --- |
| 総合商社 | 正道ルートの完成。信用で大きくなる | 正規代理店3社／従業員10人／総合商社パネル | TOKU・正道ルート |
| 配信の女王 | ライブコマースの KOL になる | フォロワー1万／1回の配信で売上100万円／自社コスメ | 3. キャリアパス |
| 目利きの館 | 鑑定士・オークションハウスを開く | 鑑定100件／委託販売の手数料収入／オークション主催 | 3. キャリアパス |
| 私設美術館 | 売らずに集める。コレクションを完成させる | 図鑑の収集率30%・60%・90% | 4. 消費・コレクション |
| 裏社会の帝王 | 魔道ルートの完成 | 裏市場の売上・縄張り | TOKU・魔道ルート（実装済み） |

- 最終査定は「純資産ランク」に加えて **志の達成度（0〜3段）** を出す。エンディングは志 × 達成度で分岐（例：「配信の女王END」「志半ばEND」）。
- データ：`s.vision = { id, chosenWeek, milestones: [week|null, …] }`。志の定義は `src/data/visions.js`（`milestones: [{ title, check(s) }]`、`events`、`ending`）。

### 1.2 業界の年表（年ごとの大事件）
- 5年目から毎年、**その年の大事件** が1つ起きる（年の初めにニュースで予告 → 春に発生 → 年末に結果）。大事件はトピック2・5の仕組みを「物語」として出すもの。
- 事件はプールから、**プレイヤーの稼ぎ方に応じて** 選ぶ（いちばん稼いでいる商材・販路に関係する事件が出やすい）。

| 例 | 内容 | 仕組み |
| --- | --- | --- |
| 「転売対策元年」 | 大手メーカーが一斉に抽選の本人確認を強化 | 2. 規制 |
| 「せどり四天王の上京」 | ライバルが自分の地元の仕入れ先に乗り込んでくる | 5. 飽和 |
| 「ライブコマースバブル」 | 配信で物が売れる年。乗るか、見送るか | 3. キャリア |
| 「円安ショック」 | 海外EC の売値が跳ね、輸入は苦しくなる | 為替（実装済み） |
| 「フリマ大手の上場」 | 手数料が上がり、出品者の審査が厳しくなる | 2. 規制 |

- 事件ごとに **ミッション**（例：「規制のあとも月の純利益を前年の8割に保つ」）を出し、達成で経験点・TOKU・志のポイント。失敗しても続けられる。
- データ：`src/data/annals.js`（`{ id, weight(s), announce, start(s), mission: { title, check(s), deadline }, end(s) }`）。`s.annals = [{ id, year, result }]`。

### 1.3 ルーティンとの関係
- ルーティンは「型」を回す道具なので、**型が崩れたら知らせる**：見込み利益率が設定を下回る週が続いたら止まり、「相場が変わった」とマインが説明する（いまは黙って赤字を出し続ける）。

## 2. 販売方式・法律の変化（いたちごっこ）

### 2.1 考え方
- 現実の転売は「メーカー・販売店・法律」と「転売屋」のいたちごっこ。ゲームでは **プレイヤーが稼いだ分だけ、その稼ぎ方が対策される** ようにする。
- 対策は突然ではなく **予告 → 施行** の2段階。予告を見て、在庫を処分する・別の販路に移る・対策の抜け道（グレー）を使う、を選ばせる。

### 2.2 「目立ち度」と対策の発動
- 商材ごと・販路ごとに **目立ち度（heat）** を持つ。高値で売る（定価の2倍以上）、品薄品を買い占める、同じ商品を大量に出品すると上がる。月に1割ずつ下がる。
- 目立ち度が閾値を超えると、その商材・販路に **対策（レジーム）** が予告される。業界全体の転売ヤーの動き（ライバル。5.）も目立ち度に加わるので、自分が控えていても対策は来る。

```
heat[key] += 売った個数 × (売値 / 定価 − 1.5) の正の部分 + 買い占めた個数 × 2
heat[key] *= 0.9（月末）
heat[key] >= 100 → その key に合う対策を REGIMES から選んで予告（8週後に施行）
```

### 2.3 対策の一覧（例）

| 対策 | 対象 | 効果 | 抜け道・対応 |
| --- | --- | --- | --- |
| 抽選の本人確認 | 抽選 | 名義借り・捨てアカの口数が無効。当選率-30% | 公式の会員ランク（購入履歴）を育てる |
| 購入制限（お一人様1点＋会員証） | 店舗・行列 | 品薄品は1回1個まで | 並び屋（魔道）、会員カードを複数店で作る |
| 受注生産化 | 限定品1種 | その商品は品薄でなくなり、相場が定価近くまで下がる | 予告の間に売り切る |
| 公式リセールの開始 | チケット・限定品 | フリマで定価の1.5倍以上は出品削除 | 公式リセールで定価譲渡（TOKU+） |
| 不正転売禁止の対象拡大 | 1カテゴリ | そのカテゴリの高値転売は違法（御用ENDのカウント） | 中古・コレクター品に移る |
| 手数料改定 | フリマ1社 | 手数料+3%、出品者の本人確認 | 別の販路、自分の店 |
| ステマ規制 | ライブコマース | 案件の表示義務。守らないと炎上 | 正直に表示（売上-10%・TOKU+） |
| 輸出規制・関税 | 海外EC | 1カテゴリの輸出に許可が必要 | 資格講座「貿易実務」 |

- 施行のときは、マインが「何が変わったか・何が通用しなくなったか」を説明し、**乗り換え先のヒント** を1つ出す（例：「中古なら規制の外よ」）。
- データ：`src/data/regimes.js`（`{ id, key, announce, apply: mods, hint, duration? }`）。`s.regimes = [{ id, key, announcedWeek, startWeek, endWeek? }]`。効果は perks と同じように `regimeMod(s, name)` で引く（offers・sales・lottery が参照）。

### 2.4 規制が「緩む」こともある
- 一部の対策は数年で形骸化して緩む（例：購入制限が3年で解除）。逆に、規制のあとに **正規の中古市場** ができて新しい商機になる（認定中古の販路が開く）など、閉じるだけでなく開く動きも入れる。

### 2.5 実装メモ（実装済み）
- データは `src/data/regimes.js`、仕組みは `src/engine/regimes.js`。状態は `s.heat`（目立ち度）、`s.regimes`（`{ id, pid?, announced, start, end? }`）、`s.member`（公式ストアの会員ランク）。
- **目立ち度**：
  - 限定品・ブーム品・催事品・季節品を定価の1.5倍を超えて売ると、超えた分 ×10（プンシーなら販路にも ×4、海外ECで限定品なら +3）。
  - 品薄品を買うと商品に +2/個、行列なら行列に +4/個。
  - 月末に ×0.9。ライバルも毎月足す（エジソン→抽選、曹操→行列、ビリー→プンシー、ゴッホ→海外EC）。
  - 100を超えた key に対策を **予告**（徳川家康「鳴くまで待とう」＋マイン）→ **8週後に施行**。予告と予告の間は12週あける。ステージ2から。
- **実装した対策**（商品はエスカレートする：公式リセール → 不正転売禁止 → 受注生産）

| 対策 | 対象 | 効果 |
| --- | --- | --- |
| 公式リセールの開始 | 商品 | フリマ（プンシー・アマクリ）では定価の1.5倍まで。施行の日に高値の出品は値下げ |
| 不正転売禁止の対象拡大 | 商品 | どの販路でも定価の1.2倍まで |
| 受注生産化 | 商品 | 品薄でなくなり、相場が定価近くまで下がる。抽選・行列の対象から外れる |
| 抽選の本人確認 | 抽選 | 名義借り・捨てアカが選べない。当選率 ×0.7、公式ストアで買うほど（会員ランク）最大 ×1.5 まで戻る |
| 購入制限（お一人様1点） | 行列 | 戦利品は1個まで、成功率 ×0.8。**3年で緩む** |
| フリマの手数料改定 | プンシー | 手数料 +3% |
| 輸出規制 | 海外EC | 限定品は資格「貿易実務」（予告のあとに講座が出る）がないと出せない |
| 認定中古市場の開設（商機） | 中古品 | 不正転売禁止・購入制限の施行から16週後に開く。中古の相場 ×1.15（2年） |

- 設計からの変更：
  - 「不正転売禁止」は御用ENDのカウントではなく、**出品価格の上限** にした（予告で8週の猶予があり、出品画面にも「規制により◯円まで」と出るので、知らずに逮捕されることはない）。
  - ステマ規制はライブコマース（3.）と一緒に入れる。
- **画面**：メニュー「業界の動き」（旧「仕入れ先と番付」）に、規制（予告中・施行中・終わった）と「目立っているもの」を追加。
- **自動プレイ**：10回で1ゲームあたり5〜9件の対策が、6年目ごろから起きる。10回ともステージ5、平均資産 約7,900万円。

## 3. 商材・顧客によるキャリアパス

### 3.1 顧客層（オーディエンス）
- 売った商材のジャンルごとに **顧客層** が育つ。評価の高い取引ほど伸びる。いまの「評価」は全体の数字だが、顧客層は「誰に売れているか」。

| 顧客層 | 育つ商材 | 転身先 |
| --- | --- | --- |
| 美容 | コスメのミラー（開拓で追加済み）、香水・コスメ（追加） | ライブコマースKOL |
| ガジェット | ゲーム機・PC・カメラ | レビューメディア（アフィリエイト） |
| コレクター | 絶版本・トレカ・アンティーク | 鑑定士・オークションハウス |
| ファッション | スニーカー・スカーフ・財布 | セレクトショップ・自社ブランド |
| インバウンド | 和雑貨・工芸（こけし・番傘・重箱） | 越境EC・免税店 |

- データ：`s.audience = { beauty, gadget, collector, fashion, inbound }`（0〜）。商品に `aud: 'beauty'` を持たせ、`finalizeSale` で `+1 × 評価係数`。

### 3.2 転身（キャリアカード）
- 顧客層が一定（例：500）を超えると、その道の **キャリアの誘い** がイベントで来る（ヒーローが誘う）。受けると専用のコマンドとパネルが開く。複数持てるが、志（1.1）にできるのは1つ。
- 例：**ライブコマースKOL**（誘い：楊貴妃「あなたが勧めると、みんな買うのね」）
  - 夜のコマンド「ライブ配信」：出品中の美容品をまとめて売る（売れる数 = フォロワー × 購買率 × トークの上手さ）。手数料ではなく **紹介料** が入る案件配信もある。
  - フォロワーは配信で増え、炎上で減る。ステマ規制（2.）・TOKU と連動。
  - 経験点の使い道：配信の練習・企画に **対人・情報** の経験点を使う（余りがちな2つの受け皿）。
- 例：**鑑定士**（誘い：葛飾北斎「おぬしの眼、本物よ」）
  - 外出「鑑定の依頼」：他人の品物を鑑定して手数料（目利き × 件数）。真贋を外すと信用が落ちる。
  - 「委託販売」：預かった品を自分の販路で売り、手数料20%。在庫を持たずに売上が立つ。
- 例：**レビューメディア**（誘い：エジソン「発明は売れてこそだ」）
  - メーカーから提供品が届く（タダで仕入れ）。ただし辛口レビューを書くと提供が止まる（TOKU と天秤）。

### 3.3 キャリアパスと経験点
- 転身先ごとに、**その道の経験点の使い道** を用意する（ライブ配信＝対人、メディア＝情報、鑑定＝情報・精神、セレクトショップ＝技術）。これで「情報と対人が余る」問題を、振り替え（実装済み）より楽しい形で解消する。

### 3.4 実装メモ（実装済み）
- データは `src/data/careers.js`、仕組みは `src/engine/careers.js`、画面は `src/ui/careers.js`（メニュー「キャリア」）。
- **顧客層**：売れるたびに、その商品の顧客層が +（評価/100、最低0.3）。美容・ガジェット・コレクター・ファッション・インバウンドの5つ。商品と顧客層の対応は `AUD_OF`。
- **追加した商品**（マイクリのエクステンション6点）：プリティーセット・ドリームセット（美容）、サイバースタッフ＝ワイヤレスイヤホン・魔力で動く天球儀＝スマートプロジェクター（ガジェット）、苔玉盆栽・紋付羽織（インバウンド）。
  - 一般の品ぞろえとは別枠（`niche`）で、ときどき並ぶ。最初は一般の定番品に混ぜたら、安い品が仕入れ候補と出品枠を埋めて、自動プレイの資産が2割落ちたため。
- **誘い**（ステージ3から、週のはじめ）：顧客層がしきい値を超えると、ヒーローが誘う。引き受けるとコマンドが開く。断ると24週は来ない。

| キャリア | 顧客層 | しきい値 | 誘う人 | コマンド（経験点） | 中身 |
| --- | --- | --- | --- | --- | --- |
| ライブコマースKOL | 美容 | 500 | 楊貴妃 | 出品「ライブ配信」（対人30・昼夜） | 出品中の美容品を 1＋フォロワー/60×交渉で まとめて売る（手数料8%）。フォロワー300人から案件配信：「PR」と表示（紹介料8割・TOKU+1）か、ステマ（全額、30%でバレてフォロワー-25%・炎上・TOKU-5） |
| 鑑定士 | コレクター | 500 | 葛飾北斎 | 外出「鑑定の依頼」（情報20・精神10） | 2＋目利き/30件を鑑定。当たる確率 0.55＋目利き/220。手数料 1.5万×ステージ×信用。外すと信用 -8。委託販売の品を預かる（売上金の8割は持ち主へ） |
| レビューメディア | ガジェット | 250 | エジソン | 外出「レビュー記事を書く」（情報30・昼夜） | 読者が増え、毎月 読者×30円の紹介料。メーカーの提供品（タダの在庫）が届き、正直に書くか（読者+60・TOKU+2・提供が止まる）褒めちぎるか（TOKU-2） |
| セレクトショップ | ファッション | 800 | クレオパトラ | 仕入れ「海外買い付け」（技術25） | ファッションの品が相場の5〜7割で並ぶ |
| インバウンド・越境EC | インバウンド | 500 | マルコ・ポーロ | 出品「訪日客の買い物ツアー」（対人20） | 出品していない和雑貨・工芸を、相場の1.3倍で直接売る |

- **自動プレイ**：外注のパネルを取り終えてから、余った経験点でキャリアのコマンドを使う（先に使うと、ステージ5に必要なパネルの経験点が足りなくなった）。10回とも5つのキャリアすべてに誘われ（順番は回ごとに違う）、ステージ5は10/10、平均資産 約7,000万円。

## 4. 儲けを消費するルート

### 4.1 考え方
- いまはお金を使うと純資産が減るだけ。**使ったお金が別の形で返ってくる** 使い道を作る。ただし返りは不確実・遅効性にして、「貯める」との選択にする。

### 4.2 百貨店と外商
- 外出「百貨店で買い物」：自分のための買い物（時計・服・宝飾品・美術品）。買った物は **持ち物**（売れるが、売ると外商の評価が下がる）。
- 年間の購入額で **顧客ランク** が上がる：

| ランク | 年間購入額 | 特典 |
| --- | --- | --- |
| 会員 | 100万円 | 催事の先行案内（限定スイーツなどを定価で） |
| 外商顧客 | 500万円 | 担当がつく（ヒーロー：マリー・アントワネット）。限定品の優先案内（品薄品を定価で、年数回） |
| 特選顧客 | 2,000万円 | 外商経由で正規店の高級時計・宝飾品の購入枠。招待制の催事 |

- 外商経由の「優先案内」は転売すると担当にバレる確率があり、バレるとランクが落ちる（TOKU も）。**転売のために買うか、本当に自分で持つか** の選択。
- データ：`s.dept = { spentYear, rank, rep }`。新しい仕入れ元 `source: 'gaisho'`。

### 4.3 生活水準
- 稼ぐと生活水準を上げる選択肢が出る（引っ越し・車・家事代行）。上げるとやる気・体力の回復が良くなるが、毎月の生活費が上がり、**下げるとやる気が大きく落ちる**（ラチェット）。裏の人間の「金銭感覚の麻痺」（実装済み）を表の世界でも。

### 4.4 コレクション（私設美術館）
- 売らずに持っておく **コレクション** を作れる（在庫とは別の棚）。マイクリのエクステンション1,797点を「図鑑」にし、シリーズ（剣・本・時計・人形…）ごとにそろえると **シリーズボーナス**（来館者からの入館料・名声）。
- コレクションは純資産に評価額で入るが、売らないと現金にならない。志「私設美術館」のエンディングでは、収集率と目玉の品が出る。
- データ：`s.collection = [{ pid|ext, week, cost }]`。図鑑は `ext`（エクステンション番号）単位で、シリーズはマイクリの `series_id` をそのまま使う。

### 4.5 投資と寄付
- 寄付（実装済み）に加えて、**地元の店への出資**（開拓した仕入れ先に出資すると、その仕入れ先の品ぞろえが増え、飽和（5.）しにくくなる）。
- 仮想通貨の誘惑（実装済みのサトシのイベント）を、後半は「余剰資金での投資」として再登場させる。

### 4.6 実装メモ（百貨店・外商・コレクションは実装済み）
- 仕組みは `src/engine/collection.js`、図鑑のデータは `src/data/collection.js`、画面は `src/ui/collection.js`。
- **図鑑**：マイクリのエクステンションから12シリーズ×5点＝60点（刀剣・指輪・首飾り・兜・王冠・ルビー・石版・竪琴・鍵盤楽器・甲冑・宝玉・古代の人形）。シリーズはマイクリの番号のまま（1xxx＝コモン … 5xxx＝レジェンド）。
- **百貨店で買い物**（外出・ステージ3から）：美術画廊にまだ持っていない品が4〜7点並ぶ。
  - 価格の目安：コモン3万／アンコモン8万／レア25万／エピック80万／レジェンド300万円（±）。
  - 並ぶ希少度：一般はレアまで、会員からエピック、特選顧客でレジェンド。
  - 会員以上は催事の先行案内（催事スイーツ・季節品を定価で）も出る。
- **顧客ランク**：今年と去年の購入額の多いほうで決まる（会員100万／外商顧客500万／特選顧客2,000万円）。外商の評判（0〜100、初め50。30万円以上の買い物で +2）が30を切るとランクが1段下がる。
- **外商**（マリー・アントワネット）：
  - 外商顧客以上には、週7%で優先案内が来る。相場が定価を上回っている限定品を定価で1個（特選顧客は2個＋正規店の高級時計・宝飾品の購入枠）。
  - 優先案内の品には印がつき、売ると35%で担当にバレる（評判 -25・TOKU -3）。
  - 特選顧客は年に一度、招待制の催事に呼ばれる（対人+40・精神+20・やる気↑）。
- **コレクション**：在庫とは別の棚。評価額で純資産に入り、月に 0〜0.7%（希少度が高いほど）値上がりする。画商に手放すと評価額の8割で、外商の評判 -10。
- **私設美術館**（ステージ4・5点以上・500万円）：
  - 月の入館料：1点あたり コモン1,000／アンコモン2,500／レア7,500／エピック2万／レジェンド6万円。シリーズをそろえると +5万円。
  - 維持費は月15万円。安い品ばかりでは赤字。
- 生活水準（4.3）と出資・投資（4.5）はまだ。
- **自動プレイ**：余裕資金（3,000万円を超える分）で集め、5点で開館する。10回とも外商顧客まで上がり、36〜48点を集めた。ステージ5は10/10、平均資産 約8,800万円（コレクションの評価額を含む）。

## 5. vs 他の転売屋（飽和）

### 5.1 飽和度
- 仕入れ先（開拓した仕入れ先を含む）ごとに **飽和度（0〜100）** を持つ。高いほど掘り出し物が減り、値引きが浅くなり、品薄品はライバルに先に買われる。

```
saturation[spot] += 自分の利用 3 ＋ ライバルの流入（イベント）
saturation[spot] -= 2 / 週（使っていない週は 4）
仕入れ値の倍率   = 1 + saturation / 250（最大 +40%）
候補の数         = 基本の数 × (1 − saturation / 200)
```

- 開拓（実装済み）とつなげる：古い仕入れ先が飽和したら、新しい仕入れ先を開拓して移る。**開拓は「一度きりの解放」から「回し続ける営み」になる**。
- 物販交流会（実装済み）で情報を交換すると経験点が多くもらえるが、自分の仕入れ先の飽和度が上がる（情報を出すと荒らされる）。

### 5.2 ライバル転売屋
- 名前と顔のあるライバルを4〜6人置く。マイクリのエネミーの「ゴースト・偉人」（ゴースト・エジソン、ゴースト・曹操…）を **「金に取り憑かれた偉人の亡霊」＝ライバル転売屋** として使う。転売ボットは **コンピューターウイルス系のエネミー**（バイトバンディット・クリーパー…）。

| ライバル | 得意 | 行動 |
| --- | --- | --- |
| ゴースト・曹操 | 店舗の買い占め | 開拓した仕入れ先に乗り込み、飽和度を一気に上げる |
| ゴースト・エジソン | 電脳・ボット | 抽選・在庫復活をボットで総取りする |
| ゴースト・ゴッホ | アート・アンティーク | 業者オークションで競り合う（落札価格が上がる） |
| ゴースト・ビリー・ザ・キッド | 価格破壊 | 同じ商品を安く出品して、こちらの出品を売れなくする |

- ライバルも「純資産」を持って毎月増えていき、**月の長者番付** に並ぶ。抜くと称号とイベント（悔しがるライバル、組もうと言ってくるライバル）。
- 対抗手段：
  - **独占契約**：仕入れ先に対人の経験点とお金を払い、一定期間ライバルを締め出す（飽和度が上がらない）。
  - **値下げ合戦に乗らない**：自分の店・ライブ配信など、ライバルのいない販路に逃げる。
  - **協定**：ライバルと縄張りを分ける（TOKU は中立、裏切りイベントあり）。
- データ：`src/data/rivals.js`（`{ id, name, enemy, style, aggression }`）、`s.rivals = { [id]: { netWorth, spots: [...], mood } }`、`s.saturation = { [spot]: n }`。

### 5.3 実装メモ（実装済み）
- **飽和度**（`src/engine/rivals.js`）：仕入れルート（店舗せどり・電脳せどり・業者オークション・問屋）と開拓した仕入れ先ごとに 0〜100。
  - 上がる：1回回るごとに +2.5（夜は +1.25）、開拓先で買うたびに +2、物販交流会で話すといちばん使っている仕入れ先が +8、ライバルの仕掛け。
  - 下がる：使った週 -2.5、使わなかった週 -4。**週1回のペースなら荒れない**、2回以上回すと荒れる。
  - 効果：仕入れ値 ×(1 + 飽和度/250)（最大 +40%）、候補の数 ×(1 − 飽和度/200)、開拓先は品ぞろえも減る。定価で買う品薄品（抽選・行列・在庫復活）は対象外。
  - 行動を選ぶと説明に「荒れ具合 72%（かなり荒れている・仕入れ値+29%）」と出る。
- **独占契約**：仕入れ先ごとに、お金（ルートは40万円・開拓先は20万円 ×（ステージ−1））と対人の経験点120で24週。ライバルは入れず、自分の利用は半分しか荒れない。結んだときに荒れ具合 -25。
- **ライバル転売屋**（マイクリのエネミー「ゴースト・偉人」）：
  - ステージ3で ゴースト・曹操（店舗の買い占め：いちばん使っている仕入れ先を +30）、ゴースト・エジソン（転売ボット：8週間、抽選の当選率×0.6・在庫復活に気づけない・電脳 +15）。
  - ステージ4で ゴースト・ゴッホ（業者オークションの競り合い +35）、ゴースト・ビリー・ザ・キッド（価格破壊：いちばん出品している商品の相場 -12〜20%）。
  - 1人ずつ12週あけて登場。仕掛けは毎週 3% + 1%×ステージの確率（1週に1人まで）。独占契約していると曹操は引き返す。
- **長者番付**：ライバルの純資産は登場時に自分の1.1〜2倍、毎月 1.9〜3% 増える。抜くと「長者番付で抜いた！」（対人+30・精神+30）、1割以上抜き返されると挑発してくる。メニュー「業界の動き」で荒れ具合・独占契約・番付を見られる（ステージ2から）。
- **自動プレイ**：荒れ具合の差が15以上なら静かなほうへ回り、電脳が50以上なら夜は出品作業にする。10回とも ステージ5、平均資産 約7,000万円（飽和の前は約8,700万円）。ライバルの最終資産は ゴッホ 5,000万／曹操 7,500万／エジソン 1億／ビリー 1.2億 前後で、自動プレイはゴッホと曹操を抜くくらい。
