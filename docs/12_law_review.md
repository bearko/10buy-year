# 法律・手数料の年1回の見直し

ゲームの中の法律・税金・手数料の説明は、現実の制度に合わせている。制度は毎年のように変わるので、**年1回（10月ごろ）**この一覧を上から確認し、変わったものをコードと用語解説に反映する。

- 前回の見直し：2026年10月（`docs/11_expression_check.md` の2章）
- 次回の見直し：2027年10月

## 見直す項目

| # | 項目 | ゲームでの値・説明 | コードの場所 | 確認先 |
| --- | --- | --- | --- | --- |
| 1 | 所得税・住民税の税率 | 所得税5〜45%＋住民税10%の累進 | `src/engine/finance.js` の `BRACKETS` | 国税庁「所得税の税率」 |
| 2 | 基礎控除 | 58万円 | `src/engine/finance.js` の `taxFor` | 国税庁「基礎控除」（2025年分から金額が変わった。今後も改正が続く見込み） |

## 見直しの手順

1. 上の表を上から確認し、変わったものを直す（数字・説明文・用語解説）
2. `npm test` と `npm run balance` を回す（税率・送料・手数料はバランスに効く）
3. `docs/11_expression_check.md` に「何を・なぜ直したか」を追記する
4. この文書の「前回の見直し」「次回の見直し」を書き換える
