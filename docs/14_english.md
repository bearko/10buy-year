# 英語版（English version）

タイトルの「Play in English」、メニューの「English / 英語」、または URL に `?lang=en` で英語になる。端末の言語が日本語でなければ、はじめから英語で開く。セーブデータは言語に関係なく共通。

## しくみ

ゲームのコードは日本語のまま書き、**表示の直前に英語へ置きかえる**（`src/i18n/index.js`）。

- 訳は「日本語の元の文 → 英語」の辞書（`src/i18n/en/*.js`）。キーは日本語の文そのもの
- テンプレート文字列 `` `${n}件売れた` `` は「`{0}件売れた`」のパターンとして登録する。埋めこまれた値（商品名・金額など）もそれぞれ訳す
- 画面の文字は MutationObserver で訳すので、画面のコードを1つずつ書きかえなくてよい。セリフ（1文字ずつ出る）とログ・用語解説は、訳してから色分けする
- 金額は ¥ 表記に直す（`150万円` → `¥1.5M`）。訳を `null` にした文は、この単位の変換だけで済ませる
- 英語では `{0:man}` で「万」の数を金額にできる（`純資産 {0}万円` → `Net worth of {0:man}`）
- 組み立てた文で全体のパターンがないときは、「」の中の名前と辞書の短い言葉を置きかえる（最後の手段）

| ファイル | 中身 |
| --- | --- |
| `src/i18n/en/names.js` | 商品・偉人・コレクションの名前（マイクリの英語名） |
| `src/i18n/en/ui.js` | 画面のボタン・見出し |
| `src/i18n/en/game.js` | コマンド・スキル・商品・仕組みの説明 |
| `src/i18n/en/story.js` | イベント・会話・仲間・ミッション・エンディング |
| `src/i18n/strings.json` | 抽出した元の文の一覧（テストで使う） |
| `src/data/glossary.js` | 専門用語の英語（`en` / `enDesc`）。セリフの色分けとログの解説 |

## 文を足したとき

1. `node tools/i18n.mjs check` … 訳がない文の数をファイルごとに出す（TypeScript のパーサーを使う：`npm i -g typescript`）
2. `node tools/i18n.mjs missing engine/foo.js > keys.json` … そのファイルの訳がない文
3. 同じ順の英語の配列を `en.json` に書き、`node tools/i18n.mjs add story keys.json en.json` … 埋めこみ `{n}` の数と、日本語が残っていないかを確かめて足す
4. `node tools/i18n.mjs extract` … `src/i18n/strings.json` を更新

`npm test` で、(1) 抽出した文すべてに訳があること、(2) 自動プレイ2周で流れた文に日本語が残らないこと、を確かめている。

## 名前の方針

- 販売サービス：プンシー → Punsea、ミィーム → Meeme、アマクリ → Amacri、ホンモノ堂 → Honmono-do
- 商品・偉人：マイクリ公式の英語名（`mycryptoheroes/Data` の CSV）
- 日本の制度（古物商許可・確定申告・薬機法など）は日本が舞台のまま、英語で説明する
